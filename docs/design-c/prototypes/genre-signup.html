    设定写作预览

    简介

    未填

    简介是所有后续设定的源头——题材、角色、章节都从这段话读起。先写它，后面每一步都更准；糙一点没关系，写完点右栏「AI 体检」，反馈就出在下方的结果区。

    主角身份一句话立住他是谁、什么处境。例：外门杂徒林拾，在宗门扫了十年落叶。有了它，读者三秒知道跟谁走。
    本来的生活没出事之前，他打算怎么过。例：熬满十年就出宗，回家守几亩灵田过安稳日子。先给平静，后面打破它才有劲。
    突发状况什么事把平静打碎。例：一双能看见修为漏洞的眼，偏在这时睁开了。变故一出，故事才算开锣。
    必须面对的矛盾他躲不开、必须选的难题。例：用它，会被忌惮他的首座盯上；不用，废他根骨的仇永远报不了。两头都疼，读者才揪心。
    不做的后果他不动，会失去什么。例：三个月后丹田枯竭，仇人坐着的位置越坐越稳。把退路写死，读者才信他必须动。
    做了的可能结局指个方向，别写死结局。例：要么踩着漏洞一路捅上去，要么变成所有人都想挖走的那只眼。"可能"二字留悬念。
    六段公式：主角身份 + 本来的生活 + 突发状况 + 必须面对的矛盾 + 不做的后果 + 做了的可能结局

    别踩：写成世界观设定集（没人关心大陆历史）；写成作者自白（"我构思了三年"）；最后一格写死结局（"可能"=没写的部分）。

    v8.4 终态结构（本批范围：简介 + 题材）
    1. ① 简介：编辑框直接写（≤500 字）；「怎么写」＝六段模板文本指导，默认收起、点开才展开；右栏「AI 写作助手」卡片＝体检 / 补缺失 / 润色三个**并列能力**（PRO 徽标并头部 + 名称上/描述从属 + 右箭头），反馈统一显示在简介框下方结果区。
    2. ② 题材：六格（题材口味 + 主要看什么 + 绝对禁止 + 吃苦指数 + 主线战场 + 剧情轨道），每格有编号 / 怎么填 / 成书视角去处；右栏「AI 写作助手」卡片＝五行字段 AI（主要看什么 / 绝对禁止 / 吃苦指数 / 主线战场 / 剧情轨道），各答各题、答案在各自行下方。
    3. 免费版（无套餐）：AI 卡片可见 + 锁定（降透明 + 锁徽 + 收益描述「升级 PRO 解锁」），点击给升级提示；免费版写作能力完整（规范 §11 能力等价）。顶部演示视角切换器可在已解锁 / 免费版之间切换查看。
    4. 后续批次（顺序已定）：③ 世界 → ④ 开场主角（金手指＝显性字段，与简介"转机"段互相印证）→ ⑤ 主线；伏笔 / 配角 / 风格 / AI痕迹＝写作期工具。

    拍板后建议：openspec 立项（SETTINGS_ITEMS 前两步重排 + 简介/题材两面板改造 + contract 键）；世界 / 主角（含金手指）/ 主线另立后续 change。本稿不改动 prototypes/ 与任何实现代码。
