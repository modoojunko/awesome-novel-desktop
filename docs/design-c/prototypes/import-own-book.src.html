DESIGN NOTES · 非产品 UI

导入自有书：三步向导 → 两条路（同一终点）

向导选文件 → 确认卷章 → 导入方式 第 2 步是两路共用的结构确认：左解析结果、右书目录树；有卷预填，无卷可「全部放入一卷『正文』」。全部归卷且每卷≥1章才放行。
分叉直接导入 / AI 拆书，终点都是第 N+1 章从 0 规划 直接导入＝秒级建书、设定留空；拆书＝30–45 分钟、拆完开书带设定＋当前卷卷纲＋每章基线。两条路都不预生成章纲。
1 选文件：格式告知＋本地检查（秒级 · 零额度）仅 .txt、≤50MB/≤60 万字；编码自动识别＋章标题识别；解析出卷/章（有卷预填切线，无卷从空开始手工分卷）。
2 确认卷章：左解析结果／右书目录树（必做）「+ 新增卷」只在无卷时一键建全量「正文」卷；分卷走「在第N章后分卷」（案例：输入 34 → 第 35 章起归新卷），另有少一章/多一章挪边界、合并、改名、不导入误识别章；每卷≥1章且覆盖全部章才放行。此步没有 AI 建议（拆书尚未运行）。
3 选导入方式路 A 直接导入：立即建书，卷/章/正文就位，设定留空。路 B AI 拆书：建任务（不建书），任务携带第 2 步确认的结构。
4 路 B：拆完 → 开书定书名（30–45 分钟 · 关应用暂停）7 项书级设定＋当前卷卷纲＋每章基线（来自拆书卡）与正文一次写入；开书弹窗只读展示已确认结构，不再调分卷。路 A 已在第 3 步建书。
5 第 N+1 章从 0 规划章纲不预生成章纲；生成正文带设定/历史基线/上章结尾。导入章按基线归档（路 A 无基线），阶段判定排除 imported，不因 42/42 变「待完本」。

选文件 → 确认卷章 → 二选一（直接导入 / 拆书）→ 第 N+1 章从 0 规划章纲

失败面：路 A 立即建书，没有等待面；路 B 拆书失败/取消＝还没有书——任务行「续拆/重传」＋「跳过设定直接开书」（只灌章节）。删除「另建空书」话术（会造第二本书）。
