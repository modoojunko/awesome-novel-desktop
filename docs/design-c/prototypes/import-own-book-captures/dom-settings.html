灯灭的时候，陈屿正说到自己名字的来历。旧货街深处的夜明铺在暮色里亮起一盏昏黄的灯，街坊都说那盏灯有些年头了，照过三代人的归还与告别。

周雨蘅把毯子往他肩上拉了拉：「所以你留下的不是铺子，是那条路。」他把灯芯拨亮了些，窗外的雾津泛起潮气，江面上有船呜咽着驶过。

陈屿没接话。他在想灯芯上最后一个没烧完的名字——那名字他认得。夜里风大，铺子门板咯吱作响，像有人在外头轻轻叩了三下。
