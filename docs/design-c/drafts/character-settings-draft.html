    角色1

    没有找到——换个名字试试。

    压力演示：41 人；几百人同理——搜名字/别名直达，按首次出场排序。

    三样凑齐主角立得住＝想要什么＋怕什么＋凭什么。例：想查清父亲失踪、怕欠人情、凭一副能听出破绽的耳。
    能力要有限制没有代价的能力写不了冲突——代价是强制字段。例：听漏一次自瞎一日——用不用、什么时候用，都是戏。
    反派是立场每个对手都认为自己是正义的，冲突才有得写。例：丹阁要为残卷讨一个说法，不是单纯使坏。
    说话有辨识度一句口头禅、一种语气，胜过十行性格描述。例：嘴笨，急了才吐真话。
    配角别贪多出场就该有用——推剧情、衬主角、给信息，三者占一；不用一次立全：想先立的随手「＋添加」，其余归档时 AI 会识出来。
    卡片要瘦这页全文进写章提示词，越瘦越省越准。装饰性设定别往人物卡里塞。
    立人设公式：想要什么 + 怕什么 + 凭什么 + 付什么代价

    别踩：人物小传写八百字（提示词装不下）；金手指无代价（后期崩书）；反派纯坏（立场扁平）；开场给主角满级装备（后面没得写）。

    4. 人物卡＝四部分：① 角色名称＋② 角色类型（卡头一行：头像＋名称＋编号＋类型胶囊）→ ③ 基础信息（一句话人设通栏 / 剧情定位｜性别年龄种族 / 常驻势力身份·含阶级 / 外貌标签——常驻可见网格）→ ④ 认知模型（链路示意条＋六维折叠组按链序排，认知盲区与能力上限/代价强制）；字段名即问题、例句进占位符。
    5. 六维认知链（主角 / 配角 / 反派落全模型，路人不展开）：世界观→自我观→价值观⇒能力→行为⇒环境，单向不可逆闭环（认知层→执行层→结果层）；六枚折叠组按链序排、组头带层级标签；核心认知盲区与能力上限/代价为强制字段；元数据＝角色唯一 ID＋剧情定位＋人设状态（五种，实时更新）；写章 AI 沿链溯源防人设崩塌。
    6. 右栏 AI 四行（起草主角卡 / 人设精修 / 能力与代价校准 / 体检四方）：与世界页同构——采纳才写回、回执一步撤销、5 次历史、免费版可见＋锁定（ai_state 门控）；答案落对应字段下方。
    7. 注入口径（后台规则，不上界面）：创建期写章＝主角卡全量注入（≤400 字，沿 600 字总口子超长择要）；创建期手写骨架归档永不改写。
    8. 写作期生长（09-12 拍板移交）：归档识别收件箱（新角色预填 / 变化建议 / 疑似同一人合并、采纳入册即上树）、成长轨迹（收获 / 能力 / 认知 / 关系 / 处境，条目带剧情点 origin，写章按 as-of 注入）、回退三账联动（按剧情点截断 origin 晚于该点的写作期产物，创建期手写骨架永不改写，快照一步撤销）——全部移交后续「正文归档」change 单独设计；本稿的三栏形态（树 / 紧凑卡 / AI 收右栏）即其地基。
