题材模版：结构随题材，值从空白开始v3

模版制：题材决定「长哪些设定项」；空模版是一等公民，所有值留空等人填；内置预填模版只是帮你把值填好——每一项随时可改、可清、可加，绝不锁死。

核心想法（四条）
① 题材决定结构：选了什么题材，模版就长什么设定项——仙侠有「境界体系 / 法宝与资源 / 宗门与势力」，悬疑刑侦有「案件与诡计 / 线索链 / 侦探与搭档」，外加通用四区块与剧情骨架。「题材设定影响很多」的正解＝不同题材长不同的表单。
② 空模版是一等公民：所有值默认留空，placeholder 提示这类书通常怎么填。留空＝AI 按题材共性写；填了＝AI 按你写的来。
③ 预置＝帮你填好的模版：每题材内置 2-3 套预填模版（值与 awesome-novel 同源），套用＝填值不是锁定，套用后与手填无异。
④ 编辑能力全面保留：行级增删改、区块级「AI 帮我填」、任意清空回到空模版。禁忌与写作指南仍为只读知识（自定义规矩走「风格」面板）。
口径前提
  • 数据模型是本期唯一动 schema 的地方：GenreDefinition + template（sections[] + presets[]），novel 侧 genre settings 增 template_values（按 sectionKey 的 map）；旧 config_overrides 四键过渡期双写，提示词组装侧兼容读取。
  • 「空模版」不是一条数据，就是 template_values 全空的态；预置值取 awesome-novel xianxia.md 同源（凡人修仙流共 26 项，页面计数动态算）。
  • 建书即选题材保留，建书后默认空白自填——最初「设定项多」的抱怨由此化解：默认是带占位提示的空表单，不是一堆预填值。
  • 「AI 帮我填」接 settings-ai-qa 在途的 fieldGuide 单源方案（66 字段 AI 填仅 23% 的修复线）。

    推荐 v3 模版制整稿落地。工程切片：① 后端题材库增 template 结构与 presets（唯一 schema 变化，随 seed 更新）；② 面板改模版编辑器（区块渲染器 + 模版来源 chips + template_values 读写，旧 config_overrides 双写过渡）；③ 建书后默认空白自填；④ 提示词组装优先读 template_values、兼容旧键。
    1. 为什么这次方向是对的：它同时满足用户两条要求——「不同题材相关设定项不一样」（结构层题材化）与「留空给人填写修改、选了题材不定死」（值层空模版 + 预置可选可改）。v1 藏值、v2 锁值，都输在把「值」当成平台的，而不是作家的。
    2. 「设定项多」的最初抱怨依然被解决：默认看到的是空模版（占位提示 + 少量区块），不是 19 行既成值；专属区块让无关设定项不再出现；AI 帮我填把「从零写」的成本再压一层。
    3. 预置的价值重述：预置不再是「平台的默认值」，而是「帮你填好的模版」——一键从空白到填好，再按自己这本书改。这与 awesome-novel 的 genre 档案同源，但编辑权完全交还作家。
    4. 认账的代价：这是四稿里唯一动 schema 的方案（template/template_values），且提示词接线需后端配合——与 settings-ai-qa 的 fieldGuide 单源方案合流推进，避免两套字段字典。
    5. 演进方向（不在本期）：作家可把自己改好的模版存成「我的模版」（custom presets）；设定流其他面板的提示/字段按题材微调（题材影响面再外扩）。
