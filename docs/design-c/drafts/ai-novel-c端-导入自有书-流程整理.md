## 0. 一句话

作者把自己的书搬进来，**两条路选一条，终点相同**：

- **只导入正文**：定书名 → 卷/章/正文秒级就位，立刻能写能改；设定、伏笔、钩子、卷纲留空。**代价：之前章节埋的伏笔/钩子/设定变化不会带过来。**
- **拆书提取设定**：等拆书（约 30–45 分钟）→ 开书定书名 → 设定＋正文一次到位，并落一份**截至最后一章的状态基线**（7 项设定＋未收伏笔/钩子＋当前卷卷纲）→ 逐项确认。

两条路之后都做同一件事：**第 N+1 章从 0 规划章纲**（AI 拆章或自己写），不预生成章纲。手动拆书任务（拆别人的书）维持现状不动。

## 1. 背景与问题

存量作者（在别处已写了几十万字）的最高频诉求是「把书搬进来，接着写」。今天两条链各缺一半：

- **书架「导入」**（`ImportNovelModal` → `POST /novels/import/parse|persist`）：能建书＋卷/章/正文就位，但**设定基本为空**——只有免费档机械处理（首章题材匹配＋简介抽取），AI 十维设定一概没有。
- **写作工具「拆书」**（`/tools` → `deconstruct/` 域）：能拆出 10 份设定产物并「建书」灌设定（7 设定项＋章卷结构/人物关系/写作技法），但**书不带章节**，且出口定位是「拆别人的书」——产物是参考材料。

本需求把「稿子是我自己的」变成一条完整链路：**导入 = 用拆书的管线处理自己的书，完成后的出口不是「参考材料」而是「开书」**。

## 3. 目标流程（三步向导 → 两条路，同一终点）

```
① 选文件            格式告知＋检查（仅 .txt；单文件 ≤50MB；**不限字数**——超过约 60 万字时拆书自动分段）；解析卷/章
                    解析：原文有卷 → 按卷预填；无卷 → 全部章待归卷
② 确认卷章（必做）  左：解析出的章；右：书目录树（样式同写作页目录树）
                    有卷 → 确认或微调；无卷 → 「全部放入一卷『正文』」或新建卷后选章归卷
                    放行条件：每卷 ≥1 章、全部章都已归卷
③ 导入方式          路 A 直接导入开始写作（秒级；设定留空）
                    路 B AI 拆书补充设定（30–45 分钟；拆完开书：设定＋当前卷卷纲＋每章基线）
```

两条路的终点一致：**第 N+1 章从 0 规划章纲**（不预生成）。

### 3.1 第 1 步：选文件

- 弹窗常显格式告知：仅 .txt、单文件 ≤50MB；**不限字数**（超过约 60 万字时拆书自动分段）；章标题独占一行、删目录页、样例＋下载；
- 上传后本地检查（零额度）：编码自动识别＋章节标题识别，ok/warn/risk 就地提示；
- 解析出卷/章：**原文有卷 → 预填到第 2 步；无卷 → 所有章进「待归卷」**。

### 3.2 第 2 步：确认卷章（必做，两路共用）

- 双栏：**左＝扫描结果**（有卷列卷和章；无卷列全部章，只读参考），**右＝书目录**（按章切分的卷）。
- **铁律：卷是一段连续的章**。只允许在章与章之间切线：
  - **新增卷** = 在某章后切一刀（「在第 X 章后分卷」；或「+ 新增卷」切最大的一卷）；
  - **调边界** = 每卷「◀ 少一章 / 多一章 ▶」；
  - **合并** = 「合并到下一卷」（删掉一条切线）；
  - **改名** = 卷名可选可改。
  **不允许把单章跨卷搬动**——那会打乱故事顺序；v1 不支持单章重排。
- 原文有卷：右侧按扫描切线预填；**不调整可直接下一步**；也可切/挪边界/合并/改名。
- 原文无卷：右侧为空、下一步禁用；先「+ 新增卷」得到一卷「正文」（1–N），再在需要处「在第 X 章后分卷」；只有一卷也可以直接下一步。
- **卷名规则**：序号按位置自动；卷名可选可改；原文卷名保留、不重复序号；`title`＝「第N卷 · 卷名」或「第N卷」；点卷名输入框不触发重渲染。
- **卷节点折叠**：chevron 收起/展开叶子章；折叠保留卷名、章数、范围。
- 放行：卷覆盖 1..N、每卷至少 1 章（切分模型天然满足；没有卷则禁用）。
- **这一步没有 AI 建议**（拆书未运行）；structure 产物只补卷纲/摘要，不建卷、不改分卷。
- 输出＝一份「确认后的卷章结构」，路 A/B 共用。

### 3.3 第 3 步：导入方式

- **路 A · 直接导入，开始写作**：立即建书（书名默认解析名可改），按第 2 步结构落卷/章/正文；设定、伏笔、钩子、卷纲留空（简介/题材按首章机械识别，可改）；第 N+1 章从 0 规划章纲。**不消耗 token**（只在本机入库、不调用模型）。代价：之前章节埋的伏笔/钩子/设定变化不会带过来。
- **路 B · AI 拆书补充设定**：创建拆书任务（**不建书**），任务携带第 2 步确认的结构；**确认后关闭弹窗并落到「写作工具 · 任务清单/详情」**，顶部交接通知：任务已创建，拆书在应用内继续、可以离开页面；不要关闭应用（关闭会暂停，下次打开继续）。等待约 **30–45 分钟/42 章**（≈0.5–0.8 分钟/章＋8–10 分钟收尾；关应用会暂停）；**消耗约 50–80 万 token**（全书字数 ×1.5–2.5，由模型服务商按作者 Key 计费）。拆完进入**开书三态**：①确认＝书名＋只读结构＋将写入清单（可展开 10 项拆书产物与状态）；②进度＝继承「拆书已完成 10/10」，创建书→写入书级设定 0/7→卷纲与逐章基线 0/42→写入原书章节 0/42（进度条＋百分比，期间禁止关闭，中断可重试且已写入不重复）；③回执＝已写入 7 项设定/当前卷卷纲/42 章基线/42 章正文，未写入 章卷结构（以第 2 步为准），未提取 物品/认知（可补算）→「进入书内」。第 N+1 章从 0 规划章纲。
- 两条路的开书弹窗只读显示结构（如「2 卷 42 章 · 31.6 万字」），不做分卷编辑。

### 3.3.1 费用与耗时口径（作家可见，页面必须写清）

- **路 A**：0 token；秒级完成；只在本机解析/入库，不调用模型。
- **路 B**：
  - token ≈ **全书字数 × 1.5–2.5**（中文字符≈1 token 粗估；含逐章拆卡＋10 维归并＋图谱收尾的输入与输出）；
  - 时间 ≈ **0.5–0.8 分钟/章＋8–10 分钟收尾**（42 章约 30–45 分钟；不含排队，串行队列）；
  - 实际随模型分词、章节长度、断点续拆/重试次数浮动，页面标注 **±30%**；费用由作者配置的模型服务商按其 Key 计费。
- 数字由解析出的**全书字数与章数**计算，不写死；原型以 31.6 万字/42 章示例。

### 3.3.2 任务入口与完成确认（作家可见）

- **分类**：任务清单按来源分两类——**导入**（书架「导入我的书」触发）/ **拆书**（手动拆别人的书）；顶部可按类型筛选（全部/导入/拆书）；导入任务详情页头也标「导入」；
- **入口**：顶栏「写作工具」角标显示任务数（进行中＋待开书）
- **任务行三态**：
  - 拆解中：状态「拆解中」，点行看十步进度；
  - **已完成、未开书**：状态「已完成」＋meta「待开书」＋主按钮「开书」；
  - 已开书：meta「已开书」＋「进入书内」。
- **完成通知**：应用内完成时给 toast「《书名》拆完了 · 去开书」（不在任务页也能看到）；任务详情完成态同样有「开书」。
- **关闭应用＝中断**：重开后在任务清单显示已中断/已失败，点「从断点续拆」；不承诺「后台继续」。

### 3.3.3 模型与配额门（2026-10-17 拍板）

- **模型门**：第 3 步卡 A 显示「模型：GLM-5.3 · 已配置」；未配置模型时卡 A 置灰、文案「未配置模型，拆书不可用」＋「去配置」，只剩「直接导入」可选；任务创建前必须跑模型探针。B 路不允许在无模型时建任务。
- **配额门**：进入第 3 步/创建任务前检查书架配额；已满时顶部提示「书架已满（1/1）· 开书前需要先归档或删除一本，或升级套餐」，创建按钮禁用。两条路都会占 1 个书位，必须在第 1 分钟说清，不允许等 30–45 分钟后开书才 403。
- 演示：原型顶部 demo-bar 有「模型已配/未配」「书架有空位/已满」两个非产品开关，用于看四种状态；产品 UI 内只有模型行与配额提示。

### 3.3.4 大书（超过约 60 万字）

- **只导入正文**：不设字数上限；解析/落库分批进行（流式或分段请求），前端章节列表支持搜索/筛选/虚拟滚动，不因章多卡死。
- **AI 拆书**：按**章边界**切段，每段 ≤60 万字（约 200 章）；一个导入任务下挂 N 段，串行跑，任务详情显示「第 X/N 段」＋该段十维进度；每段完成即落该段的卡片/产物，失败只重跑该段，已完成段不重跑。
- **开书合并**：设定按域合并（简介/题材/文风取最后或归并；世界/角色/关系/伏笔去重合并；主线按弧拼接；章卷结构不用、以第 2 步为准）；逐章基线按段写入各自章节；story_state 按章序折叠。回执显示「N 段全部完成」与基线覆盖章数。
- **费用/时间**：页面按实际字数算段数并累加——例如 180 万字 ≈ 3 段，token 与时间约为单段的 3 倍；第 3 步卡 A 写「大书 · 分 N 段拆解」，任务详情按段展示，不假装一次跑完。
- **为什么不直接提高单次上限**：管线单次容量按 60 万字设计；分段能在不重写归并容量的前提下支持大部头，并且失败可局部续跑。

### 3.4 两条路共用的地基（必须成立）

1. **第 2 步确认的结构是唯一事实源**：路 A 传给 `importPersist`；路 B 存到任务（新增 `structure_json` 或等价字段）并在开书时使用；拆书 `structure` 产物**不建卷、不改分卷**，只补卷纲/摘要。
2. **导入章是独立的 `imported` 状态（历史章），不是 archived**：路 B 在 imported 章上挂逐章基线（来自拆书卡，`origin=import`），路 A 无基线。`story_state` 折叠 imported 章的 accepted 行（有行才折叠）；frontier 跳过 imported → 第 N+1 章可写；**阶段判定只数 archived**，imported 不参与「待完本」。作者可编辑导入章，编辑后该章 `dossier_stale`、基线跳过并提示补算；也可对单章「归档本章」把 imported 转成 archived。
3. **不模拟 42 次提取**：路 B 的逐章基线来自拆书阶段既有卡片（零额外调用）；物品/认知缺口如实标注，可单章「补算」（archive/dossier，1 次/章）或后台全量补算。
4. **不预生成第 N+1 章章纲**：两条路都从 0 规划（AI 拆章或手写）；生成正文只带素材（设定/历史基线/上章结尾）。
5. **开书不播种设定模板**：`create_project(seed_settings=false)`——否则「未勾选项未写入」「只导入正文设定为空」都不成立。

## 4. 与既有稿的关系

- **轻量开书双路径**（2026-10-09，新书怎么开始）：姊妹篇——那是「从零写」的轻量入口，这是「带着存量来」的轻量入口。共享立场：AI 产物一律「待确认」制，不悄悄替作者做主；共享词汇：流程条/耗时/产出 meta。
- **拆书 v9 设计稿**（`ai-novel-c端-拆书.html`，任务流视觉真值）：清单/详情/进行中形态**原样复用**；出口按任务来源分型——手动任务出口不动（本稿不重画），导入触发任务出口＝开书弹窗（本稿新增）。
- **互指导航**：导入弹窗说明行指路「拆别人的书学技法 → 写作工具 · 拆书」；开书弹窗说明行反向指路。两链不混但互相找得到。

### 6.1 第二轮拍板（2026-10-17，用户「按你推荐」采纳 9 条）

1. **卷模型**：连续切分（第 2 步切分点编辑器）；不允许单章跨卷；A/B 共用同一校验器（切线递增、覆盖 1..N、每段非空）。
2. **章号/标题**：保留现有卷内章号存储；界面统一显示「全书第 N 章」（由卷序+章序算）；标题剥掉「第X章/第X卷」序号后存储、显示时拼一次；一个归一函数全链共用。
3. **每章基线**：接受「每章只读首尾约 6000 字」的覆盖；物品/认知标未提取；需要时按章、按域补算；补算不替换已采纳行、不顺手归档。
4. **编辑失效**：作者改导入章 → 当前章标 `dossier_stale`，并提示「后面章节可能受影响」，由作者决定是否批量补算；不静默跳过、不自动全废。
5. **伏笔**：书级伏笔台账为唯一来源；逐章卡只补「第几章埋/收」的锚定；不双写。
6. **阶段**：导入章即使被作者归档，也不计入「待完本」；书内保持「写作中」（书级继续标记）。
7. **开书进度**：先测真实 p90；≤2 秒删掉四段进度，只留按钮 loading＋回执；>5–8 秒才做一条真实计数，不用内部实现清单。
8. **A 路补拆**：v1 明确不支持「对已导入书补拆设定」；卡 B 写清「之后只能手动补」；二期再评估。
9. **开书前调整结构**：开书确认页提供「调整结构」入口，回到第 2 步改（章节尚未写入，安全）；不用删任务重来。

> 开发前仍须补：第 2 步的**章节级修正**（删除/忽略误识别章、重命名、正文前 200 字预览）与**结构 risk 显式确认**——当前原型只画了切分，PM 复审的 P0-1 仍成立；这部分不改变上述 9 条口径。

## 8. 边界与降级

- **路 A 的损失**：伏笔/钩子/设定变化/卷纲都不带；第 N+1 章 AI 拆章前需作者补主线与当前卷卷纲。弹窗卡 B 明示代价，不做事后补偿承诺。
- **拆书失败/取消**：没有书。任务行「续拆/重传」（现有）＋「跳过设定直接开书」降级口（只有章节）；设定页之后手填或接 `ai_backfill`。
- **need_reupload**：任务缺源 → 重传续拆（现有）；重传成功后照常开书。
- **导入章无章纲**：写正文不硬依赖章纲（素材组装制）；要拆卷才需主线非空——主线由拆书 mainplot 灌入或手填。
- **档位**：拆书自备 Key 不分档；开书/导入免费；生成正文 PRO（现状）。卡A 耗时文案标前提。
- **大文件/格式**：仅 .txt，单文件 ≤50MB 是技术上限；**字数不设上限**。超过约 60 万字的书，拆书自动分段（按章边界，每段 ≤60 万字），费用/时间按段累加；「只导入正文」不限字数，分批解析/写入。.md/.docx/.epub 第一期不支持且不保留旧入口，弹窗明示「暂不支持」不给转换承诺。
- **隐私与脱敏**：自有书走拆书管线，沿用 `deconstruct/sanitize.py` 出口脱敏与 quote 回验，无新增面。
- **拆完不想开了**：产物保留，任务行可「稍后再说」随时回来开书；不想要了删任务（现有，连带清产物）。

## 9. 验收要点（草拟）

1. **大书**：上传 180 万字/240 章的 txt，A 路可不设字数上限导入并正常打开；B 路自动切 3 段，任务详情显示段进度，费用/时间按 3 段累加；某段失败只重跑该段；开书回执显示「3 段完成」与基线覆盖章数。
2. **模型与配额门**：未配模型时 AI 卡置灰、显示「未配置模型，拆书不可用」＋「去配置」，直接导入仍可选；已配时卡 A 显示模型名；书架满时第 3 步顶部提示且创建按钮禁用；两者都在第 3 步前判定，不拖到开书。
3. **任务分类**：任务清单类型标签「导入 / 拆书」正确；顶部「全部/导入/拆书」筛选只显示对应任务；导入任务详情页头标「导入」；两类共用十步进度与三态。
4. **完成确认**：任务完成后清单行显示「已完成」＋「待开书」＋主按钮「开书」；已开书行显示「已开书」＋「进入书内」；顶栏「写作工具」角标可见；应用内完成有 toast；关闭应用重开后显示中断并可从断点续拆。
5. **导入完成交接**：拆书路确认导入后落到写作工具任务清单/详情，顶部通知可见且文案为「应用内继续 / 不要关闭应用 / 关闭会暂停、下次打开继续」；任务行状态与通知一致；不出现「后台会跟进」；CTA 文案为「创建任务并查看进度」。
6. **三步向导**：①选文件（格式告知/检查）→ ②确认卷章（必做）→ ③导入方式；未确认结构时第 3 步不可达。
7. **第 2 步·原文有卷**：左侧显示扫描卷/章；右侧按扫描切线预填，**不调整可直接下一步**；调整只允许切/挪边界/合并/改名，不允许单章跨卷；每卷≥1章、覆盖全部章才放行。
8. **第 2 步·原文无卷**：左侧列出 42 章、右侧为空、下一步禁用；点「+ 新增卷」得到 1 卷「正文」（1–42），再在第 X 章后分卷；只有一卷也可直接下一步。
9. **共用地基**：两条路导入后续写光标都落在第 N+1 章（不是第 1 章）；书本阶段保持「写作中」；归档页 B 路标「已导入基线（可复核）」，A 路标「已导入（未归档）」；作者可编辑导入章，编辑后基线标 stale；可单章归档转 archived。
10. **编辑导入章**：作者可改导入章正文/标题，状态仍为 imported；若有基线则标 dossier_stale、不参与 story_state 折叠并提示补算；续写光标不因编辑回退；删除导入章按现有链/引用规则处理。
11. **路 A**：第 3 步选直接导入 → 定书名 → 书与卷/章/正文 ≤数秒就位；无拆书任务；设定除简介/题材外为空；弹窗明示「伏笔/钩子/设定变化不会带过来」；第 N+1 章无预生成章纲。
12. **路 B**：第 3 步选拆书 → 只出现任务、不出现书；任务携带第 2 步结构；完成后开书 → 设定＋正文一次到位；每章有基线节点（来自拆书卡，物品/认知标「未提取」）；当前卷卷纲就位；第 N+1 章折叠历史基线后从 0 规划。
13. **第 3 步费用**：路 B 卡片写明 token 估算（全书字数 ×1.5–2.5，示例 50–80 万）与时间公式（0.5–0.8 分钟/章＋8–10 分钟收尾，示例 30–45 分钟），并标注 ±30% 与「由你的模型服务商计费」；路 A 写明 0 token、只在本机入库；数字随解析出的字数/章数变化，不写死。
14. **开书确认/进度/回执**：确认页显示书名、只读结构、将写入清单，展开可见 10 项拆书产物状态（写入/不写入/未提取）；点「创建并打开」进入进度（顶部继承「拆书已完成 10/10」，依次创建书→写设定 0/7→卷纲与基线 0/42→写章节 0/42），期间关闭入口隐藏；完成后出回执（写入项/未写入章卷结构/未提取物品认知）与「进入书内」，点击进入书内。
15. 拆书失败/取消：「续拆/重传」＋「跳过设定直接开书」得到只有章节的书；无「另建空书」入口。
16. 导入章不产生 42 次新提取；`story_state` 能折叠导入章；书架阶段不因 42/42 归档变「待完本」；编辑导入章后基线标 stale 并提示补算。
17. 结构判定三态文案与拆书创建页逐字一致（parity）。
18. 导入弹窗：**仅 .txt 可选**（.md/.docx/.epub 标暂不支持，旧 md/docx 入口不保留）；格式要求与样例在第 1 步直接可见且可下载；单文件 ≤50MB，字数不设上限（超约 60 万字拆书自动分段），与后端一致。
19. 两路都不播种设定模板：未写入的项在设定页保持「未填」，不回显模板默认值。
20. **卷名**：新增卷默认显示「第N卷」且卷名输入为空；输入卷名后生效（如「第3卷 · 归乡」）；原文卷名保留（如「第1卷 · 沉船」）；新增/删除卷后序号按位置重排、卷名不丢；空卷仍按规则禁用下一步。
21. **切分点编辑器**：在第 12 章后分卷 → 1–12 / 13–24 / 25–42；「少一章/多一章」挪边界且两卷非空；「合并到下一卷」；卷名可改；chevron 折叠；没有「单章跨卷」操作。
