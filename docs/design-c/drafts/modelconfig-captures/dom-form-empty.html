如何获取 Key

个人身份即可 · 不需企业资质
  1. 注册腾讯云并完成个人实名认证（身份证，几分钟，一次性）
  2. 打开 EdgeOne 控制台 → Makers → Models → API Key，点「创建 API Key」并复制
  3. 回到这里粘贴保存，保存后会自动测一次连接（消耗极少额度）
