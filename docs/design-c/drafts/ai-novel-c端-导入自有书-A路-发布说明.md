# 导入自有书 · A 路（直接导入）发布说明草稿

## 作者会看到什么

- 书架「导入我的书」改为三步：选文件 → 确认卷章 → 直接导入。
- 只支持 `.txt`：单文件 ≤50MB，字数不限；第一步直接给出格式要求、示例和「下载示例 .txt」。
- 第二步可以按章切分卷、改卷名、合并/拆分、「不导入」误识别章；结构 risk 会要求勾选确认。
- 直接导入 0 token、只在本机解析入库，不需要配置模型/Key；立即建书。
- 导入的章显示「原文」：可编辑、可回看，续写从全书第 N+1 章开始，不会回到第 1 章。
- 设定留空，简介按第一章自动识别（可改）；伏笔/钩子/设定变化不会从原文自动带过来。
- 导入后不提供删章；要重来，删掉这本书重新导入。

## 不再提供

- 旧的书架导入入口（md/docx/epub、10MB、旧预览树）退役。
- 第一期不提供 md/docx/epub 转换；需要先把文件另存为 `.txt`。

## 旧书

- 旧版本导入的书会保留可读；其章节按「原文」处理，续写落到全书 N+1。
- 旧书的设定不会自动补；需要时在设定页手动补。

## 数据与隐私

- 直接导入只在本机解析/入库，不把正文发送给模型服务商。
- 导入是新建一本书，不覆盖原有书；同一份文件重复导入会再建一本（第一期不做指纹查重）。

## 已知限制（后续版本）

- AI 拆书补设定（B 路）未在本版开放。
- 物品/认知不提取；逐章基线不在 A 路。
- 导入后不支持删章；逐章重命名/正文预览留到后续。
