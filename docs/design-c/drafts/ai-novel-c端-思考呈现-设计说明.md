# 正文工作台「思考呈现」设计说明

2026-10-20 · 原型：`ai-novel-c端-思考呈现-原型.html`（真界面基线，HEAD@933cd 实抓）
· 状态：**待评审拍板** · 关联挂账：思考呈现（#852，10-15 立）

## 1. 背景与问题

思考型模型（MiniMax M3.1-Flash 实测）写一章正文要**先思考数分钟才出第一个字**
（10-20 实测：291 秒完成，其中思考约 4 分钟；现有正文首字宽限 600 秒）。
当前实现把模型的思考 delta 静默丢弃（anthropic 路径只接 `text_delta`，
openai 路径只读 `delta.content`），思考期前端只有一个占位行——
**等待呈现与卡死无法区分**，10-20 用户连续两轮把正常生成报成「卡首字」。

## 2. 设计原则（本原型四态共同遵守）

1. **思考走独立通道**：思考内容只进思考面板，永不混入正文（正文剥离守卫不动）。
2. **作家可读**：全程用产品语言（思考过程/展开回看/已保留），无实现词汇（check 脚本黑名单兜底）。
3. **不打断写作**：写作期思考收进一条细条，展开是浮层式回看，不与流式正文抢空间。
4. **等不到正文，至少等得到思考**：超时终局也把已产出的思考内容留给作家。

## 3. 四态设计

| 态 | 形态 | 说明 |
|---|---|---|
| ① 生成中·思考期 | **实时思考面板**（占位行让位） | 面板一出现，原「模型思考中，等待首字」占位行整体退场——秒表、活着、停止（顶条）都在面板与顶条上，不重复呈现；脉冲点＋模型名＋「已思考 N 秒」＋打字机流字＋自动滚尾，脚注声明「不会写进正文」 |
| ② 生成中·写作期 | **收起条** | 首字落下即收起：「✓ 思考完成 · 28 秒，正文正在写入」；点条展开回看，不中断流式 |
| ③ 完成·回看 | 收起条＋**回看抽屉** | 条留正文上方（思考 28 秒 · 生成 6 秒 · 正文 620 字账目行）；抽屉限高滚动；阅读态同样保留（思考是章的属性） |
| ④ 思考超时 | **超时卡** | 「本次生成已停止＋正文保持原样＋已保留思考内容可回看＋重新生成」；顶条生成指示同步退场 |

## 4. 原型形态决策记录

- **面板挂位**：正文区（编辑态占位行下方），不进右栏、不做独立抽屉页——等待时作家的视线本来就在正文区。
- **思考文本字号 13px＋muted**：机器元文本，与正文（serif、正文色）明确分级；左缘 accent 细线做视觉锚。
- **默认展开 vs 收起**：写作期/阅读态默认收起；完成态原型默认展开仅供评审，实际产品默认收起。
- **占位行让位原则（10-20 用户拍板）**：有思考面板就不留「等待首字」占位呈现——同一信息（活着/秒数/可停止）不出现两处；无思考的模型（DeepSeek 等）没有面板，占位行照旧。实现口径＝首个思考 delta 到达即藏 gen-line。
- **不打印到 llm.log**：思考全文不落日志（正文/Key 不落日志纪律同理），只落元数据账（见下）。

## 5. 落地契约草案（立项后实现面）

1. `ai_client.py`：StreamEvent 增加 `thinking` 类事件——anthropic 路径透传 `thinking_delta`，
   openai 路径透传 `reasoning_content`（两路径现为静默丢弃，改动面最小）。
2. SSE 契约：`phase → (think\*)? chunk\* → done｜error`，前端 `ai.ts` 消费新事件类型。
3. `llm.log` ai_call 行增加 `thinking_ms` / `first_char_ms` / `thinking_chars`（首字可观测，回答「首字什么时间返回的」不再靠估）。
4. 顺手修：MiniMax anthropic 格式 usage 解析（10-20 实测 `tokens_in=12642` 解析成功、
   `tokens_out=0` 失真——`message_delta.usage.output_tokens` 未取到）。
5. 后端首字守卫 600s 与前端「停止」交互不变；超时终局的错误事件需携带已收思考的落点（前端才留得住）。

## 6. 待拍板

1. 四态形态与文案是否认可（尤其超时卡的「已保留思考内容」是否有价值）。
2. 思考内容是否需要「复制」出口（当前原型未做）。
3. 朱雀/人味检测是否需要感知「本章曾 AI 思考」——结论：不需要，思考不属正文（原型的阅读态条文案已按「本章由 AI 生成」弱化表述）。
