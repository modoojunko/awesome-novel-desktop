本目录（docs/design-c/）的分工

pages/（本集）——现行实况的导航版页面集＋组件库：讲「现在长什么样、页面怎么走」；随实现演进而更新。

prototypes/——视觉真值：parity 门禁（design:check <0.2%）消费的基线原型；改实现先改它并登记 ADJUSTMENTS.md。
