# C 端卖点整理（爱小说 · Awesome Novel）

> 用途：S 端官网首页与 C 端落地页的共用文案源。核心主张「人铸灵魂，AI 行笔墨」贯穿全页。
> 文案原则（PM 评审口径）：面向小禾/老赵说话，**不用技术词与内部术语**（SSE、Token、API Key、门控、提示词、diff 等一律翻译成用户语言；「提示词」是内部环节，不向用户呈现）。
> 状态标注：✅ 已落地（有真实功能支撑）｜🚧 规划中（PM 已规划，未上线）

## 一、定位主张

- **主主张：人铸灵魂，AI 行笔墨**
- 概念公式：**小说创作 = 人的构想 + AI 的笔力**
- 副主张：AI 是笔，你才是作家。构想由你铸就，文字交给 AI，成稿由你拍板。
- 差异化：AI 是创作伙伴而非代笔，每一个故事决策都由你掌控（`README.zh.md`）
- 目标用户：中文小说作者——新手（怕复杂、想尽快写正文）与老手（时间紧、讨厌流程绑架）

## 二、三大痛点支柱（✅ 已落地）

### 01 怕烂尾？——开写前有蓝图，过程中有人盯

| 用户语言（对外） | 内部口径（备注） |
|---|---|
| 一步一步来，不给你跳步的机会：设定、大纲、章纲、正文、归档，每一步都有检查，缺了什么会提醒你补上 | 六阶段门控工作流，阶段验证门，缺前置条件无法跳级 |
| 卡住了？让角色先演一遍：把角色放进场景里走一回合，合情合理的走向自然浮现 | 剧情推演引擎（回合制 seed/round/rewind） |
| 写一页是一页，随时回到之前任何一稿：自动保存每一版，写坏了也不怕，一键找回 | 版本历史 + 行/词级 diff 对比恢复 |

### 02 不像你？——越写越像你

| 用户语言（对外） | 内部口径（备注） |
|---|---|
| 你的文风，AI 一学就会：设定一次叙事方式与描写习惯，全书 AI 都按你的风格写 | 写作风格设定（叙事身份/核心原则/描写技法/叙事基调） |
| 去 AI 味：避开一眼假的机器腔——疲劳词、固定句式、套路描写，帮你拦下来 | 反 AI 痕迹：疲劳词、句式偏好、改写算法 + 7 类套路模式 |
| 10 秒建书，旧稿也能接着写：填个书名就能开写；已有稿子导入后无缝续写 | 建书即写 + 导入 → 补设定 → 续写流程 |

### 03 有 AI 味？——机器腔与逻辑漏洞，定稿前拦下

| 用户语言（对外） | 内部口径（备注） |
|---|---|
| 每段写完，自动质检：逻辑硬伤、风格跑偏、人物走形、节奏失衡，生成完当场揪出来 | 六维质量检测（逻辑/风格/角色/密度/语言/节奏） |
| 记得前文的 AI：它清楚前情、记得角色、守你的文风，接得上你写的内容 | 上下文感知生成（前文情节 + 角色状态 + 风格规则注入） |
| 从生成到定稿，全程防 AI 味：AI 写作时就带着你的风格，成稿前再整体查一遍 | 风格/反 AI 规则注入提示词组装 + 成稿净化 |

## 三、附加卖点（✅ 已落地）

| 用户语言（对外） | 内部口径（备注） |
|---|---|
| 数据只属于你：稿子存在自己电脑上，关网也能写，不收集你的数据；换个电脑，拷走就能带走 | 本地存储、核心功能离线可用、拷贝目录即迁移 |
| 模型随你选：接你自己的 AI 服务，DeepSeek、Kimi、通义等主流模型都支持，每本书可各用各的 | 自带 API Key，多供应商，每小说独立模型 + 一键应用到全部 |
| 花费心中有数：AI 按用量计费，写之前先告诉你大概花多少，总账/月账/日账都能查 | 按 Token 计费、预估算量、用量统计（总/月/日） |
| 手工创作全免费、永远免费；同一界面解锁 AI，不搞两套 UI | 免费/PRO 双态（`docs/prd/PRD.md`） |

## 五、六阶段工作流的对外呈现（提示词为内部环节，不展示）

对外六步：**建书 → 设定 → 大纲 → 章纲 → 写作 → 归档**（对应内部 init → settings → outline → prompt → write → archive；PM 评审确认「提示词 = 内部环节而非创作流程一步」）。

| 对外步骤 | 一句话说明 |
|---|---|
| 📝 建书 | 填个书名，10 秒开写 |
| ⚙️ 设定 | 世界观与角色，可深可浅 |
| 📋 大纲 | 分卷规划，剧情不跑偏 |
| 📄 章纲 | 每章动笔前，先想好写什么 |
| ✍️ 写作 | 手写或 AI 协作，一章一章推 |
| 📚 归档 | 定稿收藏，随时回来改 |
