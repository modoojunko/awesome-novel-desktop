## 2. P0 逐条拍摄卡

### V01 下载安装与登录

**看完能做到**：从官网下载安装包，完成首次打开和登录，进入书架。
**演示环境**：干净的 Windows 或 macOS 桌面；正式安装包；一次性演示账号。

| 时间 | 画面 / 操作 | 口播 / 字幕 |
|---|---|---|
| 0:00–0:15 | 成片效果快闪：书架 → 正文 → 导出 | 「三分钟装好，马上开始写。」 |
| 0:15–0:50 | 官网下载页，选择系统，下载安装包 | 「Windows 双击安装，安装位置可以改；macOS 把图标拖进应用程序。」 |
| 0:50–1:20 | macOS 首次打开：右键 → 打开 → 再点打开 | 「Apple 会拦没有公证的应用，不是软件坏了；只需要第一次这样开。」 |
| 1:20–2:05 | 打开应用 → 登录 → 浏览器授权 → 回到应用 | 「登录会在浏览器里完成，授权完回到应用即可。」 |
| 2:05–2:35 | 首次进入书架：新建作品 / 导入 / 从备份包恢复 | 「免费版可以建 1 部作品；注册送 7 天试用，权益以应用内为准。」 |

**容易卡住的镜头**

- 浏览器授权窗口不要录到真实邮箱；用演示账号。
- 云端冷启动时登录页可能停留 30–60 秒，提前剪掉等待，但字幕要说明「首次可能较慢」。
- 不要录到任务栏里的其他项目、聊天软件通知。

### V02 从建书到写出第一章（旗舰片）

**看完能做到**：独立走完「新建作品 → 补关键设定 → 建卷 → 拆章 → 确认章纲 → 生成正文」，知道每一步为什么存在。
**前置**：演示账号已配好模型（片头用 10 秒说明，并指向 V03）；演示书为空书；AI 用本地 mock 或低成本模型。

| 时间 | 画面 / 操作 | 口播 / 字幕 |
|---|---|---|
| 0:00–0:15 | 成片第一章 + 书架 | 「从空白页到第一章，全程只用鼠标。」 |
| 0:15–0:45 | 书架 → 新建作品；只填书名 → 「创建，去写简介」 | 「新建作品只问书名，题材和设定进去再填。」 |
| 0:45–1:35 | 设定页：简介、题材、世界、角色、主线、文风、伏笔；演示 1–2 个 AI 起草 | 「七项设定都能后补；先有世界、角色、文风，AI 才写得像你。」 |
| 1:35–2:25 | 写作页 → 新增一卷（四问）→ 右栏「规划第 N 卷（AI）」三选一 | 「一卷是一个大阶段；可以让 AI 给三套走法，你挑一套。」 |
| 2:25–3:20 | 卷页 → 拆下一章 → AI 三个剧情方向 → 排上 | 「章纲是这一章写什么；AI 给三个方向，你挑一个。」 |
| 3:20–4:00 | 章纲页：补缺项 → 确认章纲 | 「章纲确认后，AI 会把它当成本章的写作依据；不确认也能生成，但容易跑偏，建议先确认。」 |
| 4:00–5:30 | 正文页 → 生成正文 → 提示词预览 → 生成 → 流式写入 | 「空章直接写入；如果这一章已经有正文，会先确认清空并替换——旧正文只能从版本历史找回。」 |
| 5:30–6:10 | 编辑一段 → 看自动保存 → 打开版本历史 | 「写坏了可以撤销；整章被替换掉的，去版本历史找回。」 |
| 6:10–6:50 | 归档 → 看变化确认入口 → 预览 | 「满意就归档；归档后正文只读，要改可以恢复编辑或重写本章。」 |
| 6:50–7:20 | 结尾卡片：V03 / V04 / V05 | 「没配模型看这条；想知道哪里像 AI 看这条；要导出看这条。」 |

**口播纪律**

- 不解释「提示词是怎么拼的」，只说「AI 会参考你的设定和本章章纲」。
- 不说「token」「上下文窗口」「SSE」；说「AI 服务」「生成」「等它写完」。
- 生成等待超过 8 秒就剪成 2 倍速，保留「正在写」的字幕，不要让观众看静止画面。
- 每一步点完停 0.5–1 秒再讲下一句，方便后期加放大和箭头。

**可选 3 分钟社交版**

保留：新建作品 → 建卷 → 拆章 → 确认章纲 → 生成 → 成片展示。设定和归档用字幕一句带过。

### V03 配好 AI 模型（第一次必看）

**看完能做到**：在「模型配置」里添加一个可用模型，测试成功，并在书里绑定使用。
**入口**：账户菜单 →「模型配置 · API Key」；或书架顶部「还没配置 API Key」提示里的「去配置」。

| 时间 | 画面 / 操作 | 口播 / 字幕 |
|---|---|---|
| 0:00–0:15 | 模型配置页 + 一张「AI 不工作」的错误提示 | 「AI 不工作，九成是这一步没做。」 |
| 0:15–0:35 | 两个页签：写作大模型 / 朱雀 AI 检测 | 「写作模型和朱雀检测是两套 Key，分开配。」 |
| 0:35–1:35 | 添加 API Key：配置名称 → 供应商 → Base URL → Key → 获取模型 → 选模型 | 「供应商选你常用的；Base URL 一般会自动填；Key 是你在模型平台申请的钥匙。」 |
| 1:35–2:05 | 思考模式（默认关）→ 测试连接 → 保存 | 「不确定就保持默认；保存前先测试连接。」 |
| 2:05–2:35 | 书内设定 → 模型设定：选模型 →「设为本书模型」 | 「每本书可以单独选模型，选好点『设为本书模型』才生效。」 |
| 2:35–3:05 | 朱雀页签：说明何时需要、Key 从哪来 | 「不用朱雀可以先跳过，不影响写正文。」 |
| 3:05–3:40 | 错误对照卡：401/403、404、余额不足、模型清单为空、超时 | 「Key 错、地址错、余额不足、模型名要手填——按这张表排查。」 |

**错误对照卡（后期做成全屏图表）**

| 现象 | 先检查 |
|---|---|
| 401 / 403 / 认证失败 | Key 是否复制完整；是否选错供应商 |
| 404 / 找不到接口 | Base URL 是否填到正确的路径；是否多了 `/v1` |
| 余额不足 | 模型平台账户余额 |
| 获取不到模型清单 | 手填模型 id；确认该供应商支持清单接口 |
| 一直超时 | 网络/代理；换一个模型或供应商 |

**安全提示（字幕常驻 3 秒）**

> Key 只存在你的电脑里；录屏、截图、发群前先遮住 Key。

### V04 人味检测：查哪里像 AI（v0.35 新能力）

**看完能做到**：在不花朱雀额度的前提下，让本地规则圈出「像 AI」的句子，按边注逐段改，再复检。
**入口**：正文页 → 右栏「人味检测 · 查哪里像 AI」（徽标：本地 · 免费）。
**关键事实**：

- 免费、本地、正文不出电脑；登录即可用，不看套餐。
- 短章 <1500 字不给人味率，但问题定位照常；先写完再打。
- 它给「人味率」和问题定位；朱雀给「AI 概率」。两者不是一回事。

| 时间 | 画面 / 操作 | 口播 / 字幕 |
|---|---|---|
| 0:00–0:15 | 一张人味检测结果页 + 正文边注 | 「朱雀说 AI 味重，但不知道改哪？先让它圈出来。」 |
| 0:15–0:40 | 正文页 → 右栏人味检测行 → 点开说明页 | 「免费、本地，不花朱雀额度；正文不出你的电脑。」 |
| 0:40–1:10 | 说明页四步图：验 → 查 → 改 → 再验 | 「先朱雀看概率，再这里定位，改完再回朱雀复核。」 |
| 1:10–2:10 | 点「了解了，开始检测」→ 结果页：人味率、红黄问题、先改哪几处、指标对照 | 「70 以上很不错，40 以下就是明显的机器腔；红的是先改的。」 |
| 2:10–3:10 | 点「标记到正文」→ 右边出现逐段边注 → 悬停看改法 | 「不替你改，只告诉你这一段为什么像 AI、怎么改。」 |
| 3:10–3:50 | 改一段 → 边注「标为已改（本地重扫）」→ 跳过 / 清除标注 | 「改完一段清一段，不用一次改完整章。」 |
| 3:50–4:30 | 太短的章节演示（打不了分）；再点「重新检测」 | 「太短打不了分，先写完；改完重新检测看分数。」 |

**口径纪律**

- 不说「指纹」「权重」「MTLD」「基线」；说「哪里像 AI」「真人常见范围」「分量」。
- 不承诺「过了人味检测就一定没有 AI 味」；说「它只提建议，发布前可以让朱雀再看一遍」。
- 不要把「人味率」说成「AI 概率」；两者方向相反，必须讲清。

### V07 拆书：把一本小说拆成 10 份材料

**看完能做到**：把一本 .txt 小说拆成简介、题材、世界、角色、关系、主线、章卷结构、文风、技法、伏笔 10 份材料，并选择「建书」或「存本地」。
**入口**：顶栏「写作工具」→「拆书」；或「任务清单」。
**关键事实**：

- 只收 .txt（书架「导入」才收 .md/.txt/.docx）；单本 ≤50MB、≤60 万字（约 200 章）。
- 章标题独占一行；UTF-8 / GBK / Big5；建议删掉目录页。
- 用你自己的模型，不设次数门槛；所选模型先过探针才能创建任务。
- 一次只跑一个任务，其余排队；可以关页面，回来取结果。
- 应用内不预览、不编辑拆解产物；产物在结果目录，或「建书」后到设定页看。

## 4. 统一录制配方

### 4.1 环境隔离（硬要求）

- 独立 `DATA_ROOT`、独立后端端口、独立前端构建产物；不要用共享 demo 栈或生产数据。
- 一次性 `e2e_manual_*` 演示账号；不要登录真实个人账号。
- AI 链路优先用本地 mock（如仓库里已有的 `client/frontend/scripts/manual-mock-ai.py`；该文件当前未跟踪，使用前确认存在）；需要真实质感时用低成本模型单独录，Key 全程遮住。
- 演示书用虚构内容，不要用真实作者稿件或版权文本。

### 4.2 演示账号与演示数据

准备三套状态，按视频切换：

| 状态 | 用途 | 要点 |
|---|---|---|
| 试用账号（7 天） | 大多数教程 | AI 行可用；账户徽标显示试用 |
| 免费账号 | V06、锁定态演示 | 1 部作品；人味检测仍可用 |
| PRO / MAX 账号 | 朱雀、剧情推演、文风蒸馏 | 仅在有需要时使用 |

演示书建议：

- 3 卷、12 章；
- 第 1 卷有 3 章：1 章已归档、1 章草稿、1 章空白；
- 设定 7 项填 5 项，留 2 项演示补全；
- 角色 6 个、关系 8 条、伏笔 5 条（2 条到期）；
- **人味检测专用**：一章 ≥2000 字、明显机器腔的正文（能出分数和红黄问题）；一章 ≥2000 字、自然口语的正文（做前后对比）；
- **拆书专用**：一本 3 卷 12 章、约 2 万字的 .txt（UTF-8，章标题独占一行）；另备一个格式有问题的 .txt 演示风险提示；
- **导入专用**：一本 3 卷 12 章的 .md/.docx，约 2 万字。

### 4.3 画面规范

- 16:9，1920×1080 录制，60fps；输出 1080p。
- 应用窗口最大化；浏览器缩放 110%–125%，保证手机上看清按钮。
- 隐藏书签栏、下载栏、开发者工具、测试横幅；正式包版本号可保留。
- 关闭系统通知、聊天软件、自动更新弹窗。
- 鼠标指针放大 + 点击高亮；输入关键字段时局部放大 1.5–2 倍。
- 每次点击后停 0.5–1 秒；页面切换后停 1 秒再口播。
- 关键按钮用后期箭头/圆角框标出，颜色跟随品牌强调色。

### 4.4 声音与口播

- 领夹麦或桌面麦，48kHz；环境噪声低；响度约 -16 LUFS。
- 短句，一句话一个动作；不用「首先/其次/最后」堆叠。
- 用户语言优先：
  - 说「AI 服务 / 模型」而不是「供应商 endpoint」；
  - 说「生成」而不是「调用」；
  - 必须说 API Key 时，补一句「就是你在模型平台申请的钥匙」。
- 视频开头 15 秒内必须出现「看完能得到什么」，不要先放 logo 动画。
- 结尾只留一个 CTA；不要一次推五个链接。

### 4.5 文件与版本

```
video/
├── raw/                原始录屏（按视频编号）
├── project/            剪辑工程
├── export/             成片
├── covers/             封面
└── scripts/            口播稿与分镜（与本文件同步）
```

命名：

```

V04_人味检测_v0.35_202610.mp4
```

成片右下角常驻小字：`v0.35 · 2026-10`。不要放大到遮挡界面。

## 8. 一句话原则

**教程不是功能说明书，是陪用户走完一次成功路径。**
每条视频只回答一个问题：看完这条，用户能多做哪一件事？
答不上来，就不拍。
