## 答案

先自查两点：

1. 码要**完整复制**，以 `AC-` 开头，前后不能多空格或缺字符；
2. 一枚码**只能绑定一个账号**，显示「已使用」说明它已被某个账号兑换过。

自查没问题仍无法兑换？把**完整的码**和尝试兑换的时间发到 **support@xingweitouzi.cn**，我们查到状态后帮你处理。

## 客服口径

- 拿到用户提供完整码后，在管理后台查询该码状态（未兑/已兑/停用/对应档位），**勿让用户反复重试**。
- 「已使用」且用户坚称未兑换过：核对兑换账号与时间，防范转卖纠纷，按后台记录口径答复。
- 权益规则：多码并存按**等级最高**档位生效，各码有效期独立计算。
- 兑换成功但权益没刷新：让用户重启客户端（权益缓存约 1 分钟），仍异常转技术查 entitlement 同步。
