# 提示词素材给量 · 决策记录（2026-09-24 拍板，未立项）

> 用途：各 AI 环节提示词该带多少设定信息的口径与验收标准。立项前的对齐台账。
> 同日关联：`卷下拆章-决策记录.md` D20/D21（人物引入 SOP／重抽排除）。

## 一、总口径（用户拍板）

> **一条设定信息进不进提示词，只看一件事：缺了它，模型会不会编、会不会用错。**
> 预算制退役（600／1200／6 张×80 字等一切限量）；"给什么"的内容策略保留。
> "足够"的验收＝提示词给模型后，回来的信息不偏差、不违背全书设定。

## 二、实锤诊断（以《我在夜晚打吸血鬼》真书）

1. **600 预算切掉势力 2/3**：`WORLD_BLOCK_BUDGET = 600` 焊在 `render_world_block`（`settings/world_model.py:35`，世界设定 v2 时代为写正文注入块设计）；`world_summary_text(…, 1200)` 的 1200 是**死参数**（内部 600 先截、二次切片永不生效）。该书舞台＋力量＋代价吃满预算后，三家势力只进一家（夜巡守夜人），血族议会与圣银教团整条被切，从略注还混称"世界细节"。
2. **拆卷没有已拆卷清单**：出第 N 卷只见上一卷结尾一句 → **卷4《血酬》与卷5《血价》几乎同一卷**（"与豢养派旧贵族做情报交易" vs "以猎杀换旧贵族情报"）——模型看不见已画过的走法，原样重抽。
3. **调用面**：600 零件被三家拼装共享——写正文（`prompt/context.py:25`）、设定页五个体检（`settings/ai_router.py` 五处）、拆卷拆章（`volumes/ai_plan.py:236` 同源）。拼装独立、零件共享，病灶在零件层。
4. **本书数据空洞**：`novel_genre` 核心承诺等全空（管道有、数据没填，题材段只剩标签）。
5. **提示词治不了的残留**：主线散文派系词（豢养派／隐匿派／旧贵族）与势力表（守夜人／议会／教团）是两套词汇——数据侧没对齐，素材全量也只减不除。另立项处理。

## 三、信息分档

- **A 类（缺了必出偏差）**：势力名＋注记、世界铁律、力量体系与上限、全部人物的名字＋定位＋一句人设（一行卡）、别名、地点、主线与结局——**全量，任何环节不设预算**；**无卡名字也要旅行**（评审增补）：派生块「本卷出场无卡名单」（名字＋首出场章＋一句功能）进拆卷/拆章/章纲素材——否则哑叔们每章都是陌生人。
- **B 类（按需，门槛是"该环节真用不到"）**：档案级深卡（八行档案＋认知六层）只给本次产物点名的人；上一章末段只给写正文；已拆卷清单只给拆卷。
- **C 类（进了有害，策略排除）**：出卡环节的伏笔台账（防提前揭）；正文不给全书正文（防复读）；章级自检的窄输入是设计（四维判据只看本章字段，多给污染判断）。

## 五、验收（不做成玄学）

仪表盘＝**越纲警告**：素材不足时模型只能编，编出的实体名撞已知集合差集警告就响。

1. 全量化改造后，用真书重抽拆卷——**「把已有势力当新势力」的假阳性清零**（今天必响，因势力只给 1/3）；模型自造实体的申报同步清零（规则 3 本就禁止新增）；
2. 抽出的卡里组织立场与势力注记一致（守夜人卖路线、教团要烧半血这类细节不走样）；
3. 回归手段＝素材拼装 fixture 断言＋真书人工 A/B——**不做遥测**（D18「拆章链路不记事件」先例）。
