================================================================
 Awesome Novel · macOS 安装说明（首次打开前请先读这一段）
================================================================

【一、安装】
把 AwesomeNovel.app 拖到右侧的「Applications（应用程序）」文件夹，
然后到「应用程序」里双击 AwesomeNovel 启动。

【二、首次打开被 macOS 拦截怎么办】
本应用暂未使用 Apple 开发者证书公证。从浏览器下载的安装包会被 macOS
打上「隔离标记」，首次启动时 Gatekeeper 可能提示：

  · 「无法打开，因为 Apple 无法验证此 App 是否包含恶意软件」
  · 「无法验证开发者」
  · 「AwesomeNovel 已损坏，无法打开」

这不是安装包损坏，也不需要重新下载。任选一种方式放行（只需做一次）：

  方法一（推荐，最省事）
    打开「终端」（启动台搜索 Terminal，或 访达 → 实用工具 → 终端），
    粘贴下面一行并回车：

        xattr -cr /Applications/AwesomeNovel.app

    然后正常双击打开即可。

  方法二（不用终端）
    打开应用出现提示时点「完成」（不要点「移到废纸篓」），
    再打开 系统设置 → 隐私与安全性，滚动到页面底部，
    点「仍要打开」，输入开机密码确认。

【三、卸载与数据位置】
卸载：把「应用程序 / AwesomeNovel.app」拖到废纸篓即可。
数据：默认保存在 ~/Library/Application Support/AwesomeNovel/。
      卸载应用不会自动删除这些数据；如需彻底清理，可在访达中按
      Command+Shift+G，输入上述路径后删除。

【四、更新】
应用内会自动检查新版本。也可以访问官网下载最新安装包：
https://www.awesomenovel.com/
