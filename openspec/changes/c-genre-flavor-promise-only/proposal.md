## Why

内测用户 2026-10-08 连报两条（设定 · 题材面板）：①「选题材和下面一堆要选要填的联动了，这里不需要」——「常见口味」胶囊点一颗就一键覆盖 02 句子/标签、03 绝对禁止勾选、04 吃苦指数滑块、05 战场勾选，实现注释里自己都标着「本面板后果最大的误点」；②「选中的框无法取消」——胶囊选中后高亮只设不清（`flavorKey` 无 toggle），再点同一颗不但不能取消，还会把作者刚改好的内容再覆盖回预置值。用户拍板（2026-10-08）：**胶囊只给 02 一句起点，不再联动 03/04/05；再点一次可取消**。

## What Changes

- **「常见口味」胶囊联动范围收窄到 02 本格**（BREAKING 交互行为）：点胶囊只写 `core_promise`（短标签）+ `promise_note`（一句起点），**SHALL NOT** 再预填 03 绝对禁止 / 04 吃苦指数 / 05 本小说斗什么（此前一次预填 02/03/04/05）；01 题材不覆盖的既有口径不变。
- **胶囊选中态可取消（toggle）**：再点已选中的胶囊＝取消——若 02 内容仍是该起点原句（作者未动过）→ 还原到点它之前的值并记回执；若作者已改过 → 只清高亮、字一个不动（撤销差量同哲学：不抹作者手敲的字）。
- **作者已写的内容，胶囊不覆盖（用户 2026-10-08 二轮拍板）**：02 非空且不是任一颗胶囊的起点原句时，点任何胶囊（含想切换的）**SHALL NOT** 改动 02，出提示说明出路（「想用起点先清空那句」）；判定按内容而非高亮，覆盖保存后重进面板高亮丢失的态。
- **切换语义**：点另一颗胶囊＝用新起点覆盖 02（记回执可一步撤销）。
- 回执文案随行为改写（「已按「逆袭打脸」给出「主要看什么」一句起点：「…」」），回执+单步撤销机制本身不变。
- 同批同步：`genreVocab.ts` 头注释（「预填 02-06」口径过时）、原型 `genre-signup.html` 的口味联动 JS、单测 2 例改造 + 新增取消/切换用例、e2e `settings-forms.spec.ts` ①a 点亮断言翻转与 ①b 长回执文案。
- 零后端改动（五字段保存契约不变）；零 CSS/共享段改动（胶囊样式复用 `.cap on` 高亮）。

## Design Impact

- **受影响端**：仅 C端（S端 无此面板，零触碰）。
- **受影响屏/弹层**：设定域「题材」面板（02 格「常见口味」胶囊行）；无弹层改动（AI 出卡链路不动）。
- **对象状态**：复用既有「选中」态（`.cap on`，状态语言总表的选中口径），新增的只是「可再点取消」的手势语义；无新状态、无新语气词（不新增 info/ok/warn/err 之外的任何形态）。
- **两端共享段**：不触碰（无 base.css / pill / notice / sk / panel / f-err 改动；无 CSS 改动）。
- **原型先行**：是（硬性流程）——`prototypes/genre-signup.html` 口味交互 JS 同批改为新行为，并在 `ADJUSTMENTS.md` 新增小节登记；注：该原型 01 格仍为老 IA（口味胶囊在 01、无题材目录选择器），此存量漂移非本批引入、不属本批修，随登记注明。
- **设计工件**：实现侧自查（纯交互语义收窄，无视觉变更；design:check 像素基线不受影响）。
- **文案口径**（§13）：胶囊 title 改为「给「主要看什么」一句起点，可改；再点一次取消」——动作词、无内部术语；取消的补救出口＝再点一次（面板内自闭合，无需跨页出口）。
