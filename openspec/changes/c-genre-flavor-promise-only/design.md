## Context

`GenreSettingForm` 的「常见口味」胶囊行（`GENRE_FLAVORS` 五颗：逆袭打脸/烧脑博弈/独宠撒糖/绝境求生/权谋布局）现状：`applyFlavor` 一次点击覆盖 02（`core_promise`+`promise_note`）、03（整表 `forbidden_list`）、04（`cost_ratio`）、05（整表 `battlefield`），`flavorKey` 高亮只设不清。内测用户 2026-10-08 两连报（联动不需要、无法取消），用户拍板「只填 02 + 可取消」。受影响面：纯前端单组件 + 原型交互 JS + 两层测试；保存契约（五字段 JSON）与后端零触碰。

## Goals / Non-Goals

**Goals:**
- 胶囊点选只写 02 两字段；03/04/05 一概不动。
- 选中态 toggle：再点取消——未改过还原、改过只清高亮；点另一颗＝切换覆盖。
- 回执+单步撤销机制保留；新回执接棒「最长回执」保住 ①b 长回执布局回归钉。

**Non-Goals:**
- 不下线胶囊行（用户明确选了降级保留，非整行删除）。
- 不动 AI 出卡链路、确认判据、保存契约；不给「常见口味」加确认弹层（AI 才走确认卡）。
- 不修原型 `genre-signup.html` 的存量 IA 漂移（01 格仍是老版口味胶囊、无题材目录选择器——非本批引入，登记不修）。
- 不在作者手改起点句时自动清高亮（高亮只是起点来源标记，保留是可接受语义）。

## Decisions

- **D1 取消的还原口径＝「原句未动才还原，动过只清高亮」**。替代方案：(a) 恒还原到点前值——会抹掉作者点完起点后自己敲的字（正是本次吐槽 ② 的反面教材：胶囊不该碰作者的字）；(b) 恒只清高亮——「取消了句子还在」会让作者困惑「取消了个啥」。实现：`applyFlavor` 时把当时 02 值存进 `flavorBeforeRef`；取消时若 `core_promise`+`promise_note` 与该胶囊预置完全一致 → 写回 `flavorBeforeRef` 并记回执，否则仅 `setFlavorKey(null)`。
- **D2 切换（点另一颗）＝直接覆盖 02**，不弹确认。理由：02 是纯文本两字段、有回执一步撤销兜底；弹层违背「胶囊＝零摩擦起点」的定位。`flavorBeforeRef` 每次应用时刷新为当时值，取消语义对「最近一次应用」成立。
- **D3 取消（还原分支）记回执、可撤销**；撤销闭包＝重新写回该起点（含 `flavorKey` 复位）。高亮-only 分支无数据变更、不出回执（spec 已钉「纯 UI 态变更 SHALL NOT 出回执」）。
- **D4 回执文案携带起点全句**：「已按「逆袭打脸」给出「主要看什么」一句起点：「<promiseNote>」，可撤销」（60-75 字）。理由：旧最长回执是五格覆盖清单文案，随行为退役；`settings-forms.spec.ts` ①b「长回执不折行、不撑宽中栏」是 2026-09-10 实测布局 bug 的回归钉，需要一条天然超宽的回执作载体——起点全句是最自然的长文案（作者在脚部即可核对填进去的是什么），不为凑长度造文案。
- **D5 高亮语义保留为「纯 UI 标记」**（不落库、不计入判据，现状不变）：取消后 `flavorKey=null`；保存/重进面板后高亮不恢复（现状亦然，加载路径不重建 `flavorKey`）。
- **D6 胶囊 `title` 与行内提示随行为改**：`title`＝「给「主要看什么」一句起点，可改；再点一次取消」（§13：动作词、无内部术语）；02 计数行「也可以先点上面的起点…」句保持成立不动。

## Risks / Trade-offs

- [取消后作者想反悔] → 还原分支的回执可一步撤销（撤销＝重新应用起点），反悔成本一次点击。
- [回执携带全句略冗余（句子就在上方框里）] → 换来 ①b 布局钉不松 + 脚部可核对；回执单行截断、全文挂 title，视觉噪音有界。
- [原型与实现交互双改漂移] → 同一提交内两处同批落笔；原型的 `GENRES` 数据本就与实现镜像同源（label 对齐）。
- [e2e ①a 后续保存断言连锁（battlefield 直查、cost 直查）] → 胶囊不再写这两格后，直查期望改回「作者手填值/空」，逐条核对见 tasks。

## Migration Plan

单提交（原型 + 实现 + 测试同批）→ CI 全绿 → 真机冒烟点一次「点选/取消/切换」三手势。回滚＝revert 单 PR，无数据迁移（契约字段不变，旧数据里的 03/04/05 值不受任何影响）。
