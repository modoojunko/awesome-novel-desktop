# 正文编辑态可见框——进入编辑态要看得出来

## Why

正文查看/编辑两态（c-prose-edit-gate）上线后实测：点「编辑正文」只有按钮消失，正文区本身**没有任何视觉变化**（无边框/无提示/光标不落），作者看不出「现在可以写了」——用户 2026-09-27 实机反馈「进入编辑态后，正文没有多出来编辑器的框」。

## What Changes

- **编辑态顶条**：编辑态呈现「正在编辑正文 · N 字」＋「写完自动保存」提示＋「完成」按钮（回查看态）；查看态顶条不变（字数＋「编辑正文」）。
- **编辑区可视化**：编辑态正文区呈现可编辑容器样式（面板底色＋细边），与查看态一眼可辨（沿用 `--surface`＝可编辑容器底色的既有设计语言）。
- **光标落位**：点「编辑正文」进编辑态后聚焦编辑器、光标落文末（继续写作的自然位置）。
- **口径修正**：编辑态退出入口由「只能切页签/切章」扩展为「切页签/切章 或 点『完成』」——仍 SHALL NOT 提供内容回退（无「取消/还原」）。

**非目标**：工具栏/富文本格式（仍纯文本投影）；改查看态与锁定语义；AI 链路行为。

## Capabilities

### New Capabilities

（无）

### Modified Capabilities

- `workbench`：MODIFIED「正文页签查看/编辑两态」（编辑态可见框＋顶条＋完成回查看＋光标落文末）。
