## Context

现有 L2 页面注入只有 `［当前页面：初始设定］`＋聚焦章 ref＋未保存标记；设定页所有面板共用「初始设定」，模型不知道当前是题材还是世界。作家说「这格」时，唯一线索是历史文本，容易指错字段。

## Goals / Non-Goals

**Goals:**
- 设定页：模型知道当前面板、字段清单、每格当前值（裁短）。
- 章内页：模型知道当前页签（章纲/正文/…），字段值仍按需 read_*。
- 零落库、零 UI 渲染；读失败不影响对话。

**Non-Goals:**
- 不做 DOM 级「鼠标停在哪个 input」的精确焦点（本轮先到面板/字段级；后续可加）。
- 不注入整段正文/长清单；不做全量页面快照。
- 不改工具注册表/授权链。

## Decisions

### 1. 前端只带面板键，不拼自然语言

`page_state.panel` 直接取 `SettingsView` 的面板键（genre/intro/world/…），`chapter_tab` 取章内页签键。后端是字段标签/当前值的唯一装配方。

- 理由：前后端标签单源；前端不复制字段表；请求体小。
- 备选：前端拼「本页字段」文本（标签两处维护，漂移）。

### 2. 后端按面板读当前值，紧凑成一行

`assistant/page_context.py`：
- genre：01 题材（theme/sub）＋02 主要看什么（core_promise/promise_note）＋03 绝对禁止＋04 吃苦指数＋05 本小说斗什么；
- intro：简介；world：八格；arc：全书故事/结局画面/主角终态/结局基调；style：身份/硬约束/手法/禁用词/句式；chars/foreshadow：名单/在途标题摘要。
- 每值裁 70-180 字，总预算 800 字；缺失显示「未填」，让模型知道字段存在。

### 3. 拼进 L2 note，不进系统前缀

与页面名/聚焦/未保存同层，随当轮 user 消息尾；不落库、不进 compact。读失败只报「当前设定面板：X（字段读取失败）」，不抛错。

- 理由：页面状态会过期，不能进历史/前缀缓存；增强面必须 fail-soft。

## Risks / Trade-offs

- [每轮读面板值有 DB/storage 开销] → 单面板 1-3 次读，值裁短；失败短路。
- [上下文变长] → 总预算 800 字；只当前面板，不是全站。
- [面板键漂移] → 前端键与 `PANEL_LABELS` 同源；未知键只回面板名/空。

## Migration Plan

无迁移；旧客户端不带 panel，行为不变。
