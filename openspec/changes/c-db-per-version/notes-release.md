## 更新内容（notes.html 正文）

### 这一版做了什么

从这一版起，**每个版本使用自己的数据文件**（文件名与版本号一一对应）：

- 打开新版会看到空书架，点一下「**把上一版的作品带过来**」即可把旧版数据复制过来；
  **原来的旧文件一个字都不会动**，一直留在原处。
- 反悔随时可装回旧版本：旧版本打开的是它自己的那份数据，不会被新版影响。
- 旧版数据会按版本各自保留（默认最近 2 份），在带回完成后可以手动清理。

### 需要注意

- **第一次打开要带一次**：这是本版起的新升级节奏（每版各自一份数据，互不覆盖）。
  若不想现在带，可以稍后从书架空态的出口行或菜单「带回旧版作品」再做。
- **换过安装目录的话**（Windows）：数据跟着程序目录走，换目录后新装的位置看不到旧数据。
  两条路：① 在旧版本里「备份」导出，再在新版「恢复」导入；或
  ② 把旧安装目录里的 `data\` 文件夹整个拷进新安装目录，重启新版即可在出口行看到旧版作品。
- **macOS**：数据固定在 `~/Library/Application Support/AI Novel`，与程序位置无关，升级不受影响。
- 若提示「旧版数据正在被另一个程序写入」，请先关闭旧版本应用再点带回。
