# c-reconcile-empty-array-fix · Design

## Context

真机失败链路（09-29，归档第 2 章）：

1. lore 收尾提示词（`archive/reconcile.py:292-297`）自相矛盾：示例形状是对象 `{"items": [...]}`，却写「JSON **数组**输出」＋「**没有则输出空数组**」。
2. 本章无新世界要素 → 模型照字面回 `[]`。
3. `_parse_json_lenient`（reconcile.py:300-313）只认对象（`find("{")`/`rfind("}")`），`[]` 两处均 −1 → None。
4. 落失败行；截断 hint 判据 `not text.rstrip().endswith("}")`（reconcile.py:233）把 `[]` 误判为「被输出预算截断」——实际 `{"items": …}` 的截断产物只可能以 `{` 开头，以 `[` 开头的输出必是完整回答。
5. retry（`reconcile_router.py:175`）重跑同一份提示词 → 同章无新要素时确定性复现。

## Goals / Non-Goals

**Goals**

- 同章无新世界要素时，收尾照常成功（空 items 或不落行），不再挂永久「失败 1」。
- 失败诊断不再对完整短输出误报「截断」。
- 提示词输出契约唯一化，从源头消灭形状歧义。

**Non-Goals**

- 不动提案生命周期/同键覆盖/采纳写回（apply_accept 语义零变化）。
- 不动章档四域提取（`archive/dossier.py`）：它有自己的提示词与解析，无「没有则输出空数组」措辞，若日后实锤同病另立 change。
- 不动 `_record/_record_fail` 用量记账与 1600 输出预算（真机 09-28 钉死的值）。
- 不动前端 ReconcilePane 渲染与重试交互。

## Decisions

**D1 · 提示词口径（源头修复）**

- lore 段改为：「JSON 对象输出，形如 `{"items": [{"key": "静默带", "value": "一句话", "set": "extra"}]}`。没有新世界要素则输出 `{"items": []}`。」——删「JSON 数组输出」「没有则输出空数组」。
- hooks 段同口径：「JSON 数组输出，形如…」→「JSON 对象输出，形如…」；「planted 输出空数组」保留（对象内字段语义，无歧义）。
- **e2e 桩锚点短语必须原样保留**（改 prompt 必 grep 桩短语的教训）：lore 的「识别新出现或变化的世界要素」（`reconcile.spec.ts:66`）、hooks 的「对既有伏笔的兑现与推进」（:60）；pytest 既有断言「不要作为世界要素提案」「planted 输出空数组」等亦不动。

**D2 · 数组兜底按「首个 JSON 结构」定形，只给 lore**

`_parse_json_lenient` 按**首个 JSON 结构的开括号**定形（`[` 先于 `{`，含字面 `[]`）：

- lore（`allow_bare_array=True`）：解析数组区间 → 包装 `{"items": list}` 返回；
- hooks：裸数组维持解析失败落失败行（三键对账契约无数组语义）。

实落时被测试撕出一版陷阱：若先走对象路径，`[{...}]` 的 `find("{")` 会捞到**数组首元素**的内层 `{`，把第一个条目误当顶层对象返回——所以必须先比开括号位置定形，再解析，且数组定形下 hooks 直接 None（不得回退对象路径）。

D3/D4 见下。（D3）截断判据 `endswith("}")` → `endswith(("}", "]"))`：`[]`/`[…]` 结尾不再报截断。既有 pytest「截断诊断」用例喂的是断在半句无收尾括号的输出，新判据下语义不变仍绿。（D4）错误消息照旧带输出前 120 字摘录（`（[]）` 正是这次定位的关键证据），不动。

## Risks / Trade-offs

- 模型对「对象形状」的遵循度：主流契约本就是对象（示例形状未变过），措辞统一后歧义消失；即便模型仍回裸数组，D2 兜底保证不炸。
- 存量失败行：用户机上已落的 lore 失败行不会被自动清（失败行只在同 kind 重跑成功时清）；重试一次即走新链路成功并清行，验收时手动点一次「重试」即可。
- hooks 裸数组仍落失败行：是有意为之（D2），失败行带可重试＋摘录，不静默。

## Migration

无 schema/数据迁移。存量 `chapter_reconcile` 失败行原样保留，重试自然收敛。
