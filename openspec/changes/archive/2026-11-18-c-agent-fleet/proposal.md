# c-agent-fleet（改型）：每页签独立的对话——独立上下文／独立记录／独立流程

## Why

一期单 agent 已具备线程级隔离（assistant_sessions UNIQUE user+book+thread_key、消息与压缩态按线程存取、跨线程天然并发无全局锁），但**流程层仍是全量共享**：任何页签都下发全 30 个工具、同一套纪律分节、轨迹无域归属。boss 拍板（2026-11-16）：**每个 tab 要有独立的上下文、独立的对话记录、独立的流程**。

经论证（2026-11-16 实测底数：系统提示词 3.8K chars＋native schema 面 8.8K chars ≈ 每轮 5-6K tok，占窗口 ~5%），「真多 agent＋总调度委派」被否决：每任务恒定多一跳分类税、分类错误召回重派、嵌套循环工程面 ~20 项，而其用户可见价值（域纪律、工具面、域身份）在单 agent 上可用**域视图**全额拿到。本 change 据此改型：**单执行体＋每页签独立流程**，原多 agent 设计降级为触发器升级项（见 Non-Goals）。

## What Changes

- **独立流程·工具面按线程收窄**：thread→域映射（ch:og＝章纲／ch:prose＝正文／set:*\＝设定／vol＝卷纲／preview＝预览），每域声明工具＝全域共享读类＋本域产卡/写类；域外工具调用**不执行**，回喂引导话术（指回对应页签）——每 tab 只走本域流程
- **独立流程·域纪律注入**：按域注入纪律分节（章纲节奏档位／正文人味红线／设定口径一致……），自身份定义单源派生＋域分节拼接，提示词包更新全域跟随
- **域身份可见**：工具→域静态映射，step/轨迹事件带 domain 字段（dock 轨迹组标「卷纲助手·N 步」），气泡署名保持「AI 助手」不拆对话
- **独立性钉进规格**：线程级会话/消息/压缩态/并发（跨线程并行互不阻塞）由「已有实现」升格为 MUST 条款＋守卫测试
- **能力围栏不变**：物理封闭的仍是全量注册表；按线程收窄的是**声明与执行视图**，注册表不增删

## Non-Goals（真多 agent 的升级触发器——任何一条命中再立项切换）

1. 工具 >45 个或域纪律分节总量 >15K 字（注意力/成本线）
2. 出现需要长时独立工作集的域任务（临时转写不污染主线程）
3. 跨域复合任务占比高到值得付恒定分类税
4. 需要域级模型编排超出 tool core 现状

## Design Impact

- 受影响端：C端 only（S端 零改动）
- 受影响屏/弹层：dock 轨迹组加域标签（增项）；无新增屏/弹层
- 原型先行：不需要（轨迹组既有形态加标签）
- 依赖：c-agent-harness 已合入 main（native tools 下发通道现成，本 change 只换「下发清单的来源」）

## Capabilities

### 修改
- `specs/writing-assistant/spec.md`——§每页注册制能力盘：页签注册的工具面即 agent 声明面（域外引导）；§助手身份结构化定义：域纪律分节自身份定义派生；新增 §页签独立对话（上下文/记录/流程三独立＋并发条款）

## Impact

- 不影响：write_gate 授权梯度、能力围栏、压缩口径、事件契约词表（domain 为增项字段）
- 风险：域映射漏配（某工具不在任何域）→ 启动校验 fail loud；域外引导话术质量（提示词包可调）
- 测试：域映射封闭校验、按线程声明收窄、域外调用引导、跨线程并发、域纪律注入
