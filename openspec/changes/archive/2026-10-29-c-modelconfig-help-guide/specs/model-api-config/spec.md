# model-api-config Delta

## ADDED Requirements

### Requirement: 配置步骤指南

模型配置域 SHALL 提供「配置指南」弹窗，按接口格式三类组织配置步骤说明：

① **弹窗结构与尺寸**——指南弹窗 SHALL 为固定尺寸（宽 880px、高 760px），SHALL NOT 随视口缩放、SHALL NOT 随页签切换改变尺寸；内容超出可视区时 SHALL 在弹窗内容区内部滚动，SHALL NOT 撑破弹窗或推挤底层页面。弹窗 SHALL 复用应用既有弹窗体系（遮罩、卡片、标题行、关闭钮）。

② **三类页签**——弹窗顶部 SHALL 提供三页签：**OpenAI 格式｜Anthropic 格式｜Google 系**，文案与排序同添加配置弹窗的「接口格式」切换器口径。三页签切换 SHALL 仅切换内容面板，SHALL NOT 关闭弹窗、SHALL NOT 重置其他页签的展开状态。

③ **页签内容骨架**——每个页签 SHALL 包含同构三段：适用范围（该格式覆盖的供应商名称，与供应商方块命名逐字一致）＋编号四步步骤（**领 API Key → 选方块贴 Key → 选模型 → 测试连接**；OpenAI 格式页签的领 Key 步骤 SHALL 附各服务商领 Key 入口速查表）＋可折叠「常见问题」（每类至少 2 条，按「现象→用户动作」表述）。全文 SHALL 使用作家可读语汇，SHALL NOT 出现实现词汇（协议、SDK、端点、探针等）。

④ **入口**——模型配置列表页页头 SHALL 在「添加 API Key」旁提供「配置指南」副按钮；添加配置弹窗的供应商方块区下方 SHALL 提供指南引导链接。两处入口点击均打开指南弹窗；弹窗内入口打开时 SHALL 按当前已选供应商定位页签（Anthropic 与 OpenCode Go·Claude 系→Anthropic 格式；Gemini→Google 系；其余→OpenAI 格式）。指南弹窗 SHALL 可独立关闭，SHALL NOT 影响添加配置弹窗中用户已填写的内容。

#### Scenario: 列表页打开指南

- **WHEN** 用户在模型配置列表页点「配置指南」
- **THEN** 打开固定尺寸指南弹窗，默认落在「OpenAI 格式」页签，可见完整四步与常见问题入口

#### Scenario: 三页签切换不关弹窗

- **WHEN** 用户在指南弹窗内依次切换三个页签
- **THEN** 内容面板随之切换，弹窗尺寸保持不变，弹窗不关闭

#### Scenario: 弹窗内入口按供应商定位

- **WHEN** 用户在添加配置弹窗选中「Gemini」方块后点供应商区下方的指南链接
- **THEN** 指南弹窗打开且定位在「Google 系」页签；关闭指南后添加弹窗已填内容保持不变

#### Scenario: 指南文案无实现词汇

- **WHEN** 审阅指南弹窗全部页签的可见文案
- **THEN** 无「协议」「SDK」「端点」「探针」「兼容层」等实现词汇，步骤与常见问题均以现象与用户动作表述
