# 发布说明草稿（s-security-hardening）

> 用途：随下个版本 tag 的附注底稿（首行进更新提醒条、全文进说明页口径）。
> 口径：大白话、无内部术语；不含"漏洞细节"。

## 首行（提醒条）
安全加固版本：登录与设备授权更安全，支持改密码后即刻登出其他设备。

## 全文
- **更安全的设备授权**：桌面应用与账号的绑定升级为"本机密钥"验证，别人即使知道你这台电脑的设备标识，也无法冒充你登录。
- **登录保护补全**：登录、注册、找回密码等入口的"操作太频繁"保护覆盖全部入口和所有访问方式。
- **改密码即刻生效**：修改密码或密保问题后，其他设备上使用旧登录状态将自动失效，需重新登录（本机作品不受影响）。
- **更稳的密码保存**：密码存储升级为业界标准算法（历史用户无感知，正常登录即可）。
- **服务器配置更严格**：关键配置缺失或不合规时，服务将明确拒绝启动（而不是带着问题运行）。
- **其他**：支付回调来源防护、接口文档默认关闭、更严格的跨域策略与安全响应头。

## 升级与部署注意（内部段，不入对外说明）
- 生产部署前确认 GitHub secrets：JWT_SECRET ≥32 位、ADMIN_TOKEN ≥16 位、PAYMENTS_GATEWAY 显式配置（门禁不通过会中止部署）。
- **无存量用户 → S端 与 C端 可同批发版**；发布页/CDN 上的旧安装包用户会在授权页看到"请升级桌面应用 + 下载链接"。
- 部署说明需包含：CORS_ALLOW_ORIGINS 列入 www 与静态托管默认域；PAYMENTS_ALLOW_MOCK 生产不配置。
- DDL 先行：users.token_version、device_grants.challenge（可空/默认值，旧代码可忽略，回滚无需回滚 DDL）。
