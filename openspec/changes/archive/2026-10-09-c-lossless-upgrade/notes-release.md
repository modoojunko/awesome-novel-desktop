# 发布说明（草稿）— c-lossless-upgrade 随版

## 用户可见变化（写给用户的口径）

### 升级后会看到什么

- 升级到本版后**首次打开**，书架会自动出现一张「把上一版的作品带过来」的提示卡，
  上面列着要带过来的**作品清单**和**模型配置清单**（含 API Key 与用量统计）。
- 点「把作品和模型配置带过来」就开始带回——**全程在本机完成、不经服务器**；
  旧文件一个字都不会动，随时可以装回旧版本。
- 带回期间请保持窗口开启，通常几秒钟完成；万一关闭了，下次打开会重新提示，
  已带回的部分不会重复。
- 完成后点「好，开始写作」——书架、设定、章节和模型配置都跟升级前一模一样，
  **API Key 可以直接用，不用重新粘贴**。（个别配置的 Key 若无法自动迁移，会明确
  提示哪几条需要在「模型配置」里重新粘贴。）
- 暂时不想带？点「稍后带」，书架顶部会留一条提醒（含「本版不再提醒」出口）；
  随时也可以从「账户 › 本机旧版本数据」里带。

### 两个已知口径（如实告知）

- **预置题材文案以你机器上的为准**：你改过（或旧版带过来）的预置题材说明，
  优先于本版出厂文案；本版**新增**的预置题材会照常补上。
- 若带回不完整（极少见），完成页会明确提示「有内容没有完整迁入」，并保留
  「重新带一次」入口，直到带回完整为止。

### 升级前须知（不变项）

- 旧版本数据文件**原位保留**；想回退就装回旧版本，旧库还在。
  （注意：可回装的安装包只在官网「下载」页保留**最近两个版本**。）
- 换安装目录＝数据不跟随：装到新目录后看不到旧作品，用「从备份包恢复」
  或把旧目录的 data 文件夹拷到新目录。
- 首次全新安装（本机没有旧数据）不会出现上面的提示卡。
