# 正文页签默认只读——查看/编辑两态补齐（用户 09-27 追加拍板）

## Why

c-ch-og-readonly（#513）把章纲/文风影子改成「默认只读＋点编辑才能改」，但刻意保留了正文页签的直接可写。用户随即追加拍板：正文也要有编辑按钮——正文页签同样默认只读，点了编辑才能写。

## What Changes

- **正文页签两态**：默认查看态＝只读阅读（编辑器 contenteditable=false，顶部一行「正文 · 字数/空章」＋「编辑正文」）；「编辑正文」进编辑态（写作、自动保存三态、AI 流式照旧）。切章回落查看态。
- **写/生成意图自动进编辑态**：AI 生成正文确认（aiWriteSignal）、顶栏「续写」恢复、「重写这一章」确认、章纲「去写正文」四条链直接落编辑态并聚焦，不打断既有流程。
- **锁定语义优先**：归档、排队门禁（frontier）、旧稿支线三套只读语义不变且优先于编辑态——锁定期不出现「编辑正文」入口（各自横幅照旧）。
- **无「取消」概念**：正文没有回退未保存修改的入口（自动保存既定口径），退出编辑态＝切页签/切章。

**非目标**：右栏 AI 动作（润色/扩写/压缩/续写）的编辑态强制（显式动作两态皆可用，采纳/流式照旧落内容）；归档「恢复编辑」后的自动进编辑态（落查看态，点「编辑正文」再写）。
