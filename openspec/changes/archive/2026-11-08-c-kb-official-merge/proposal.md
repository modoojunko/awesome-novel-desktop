# c-kb-official-merge · 官方内容并入单列表——无特权臂；详情改居中弹窗

## Why

boss 拍板（2026-11-08）：**我们自己就是官方，不因官方有特殊照顾**。官方内容即普通来源——
与自有实例合并单列表展示；「官方精选/已隐藏」特权臂、只读保护段、隐藏管理面全部退役
（后端分发/同步/覆盖层机制保留，仅界面统一）。另：右抽屉在路由转场 transform 劫持 fixed
定位下滚动后锚位漂移（真机实锤右侧空白），详情一律改**居中弹窗**（portal 挂 body）。

## What Changes

- 来源筛选：全部来源（合并）/官方/拆书/手录——官方为普通过滤项；已隐藏臂退役
- 官方条目常取并入单列表（统一实例行、来源标「官方」、点行开同一知识弹窗——无只读特殊段）
- 实例详情与知识详情：右抽屉 → 居中弹窗（createPortal 挂 document.body，绕开 transform containing block）
- 官方精选空态/重新同步/隐藏/恢复/存副本 UI 退役（同步仍随后端启动自跑；覆盖层机制后端保留）

## Impact

- 前端：KnowledgeBasePage（合并渲染/弹窗/状态清理）、kbApi 类型（src_kind 联合收敛）
- spec：knowledge-base 浏览界面（数据源分臂→合并单列表、抽屉→弹窗）＋官方精选来源 requirement 措辞
