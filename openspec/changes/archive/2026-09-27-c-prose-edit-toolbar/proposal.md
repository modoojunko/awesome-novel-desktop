# 正文编辑框工具箱——编辑态给一个真正的「编辑框」体感

## Why

用户 2026-09-27 反馈：想要一个**简单的富文本编辑框**观感（有框、有工具栏的编辑区），但**实际编辑与存储仍是纯文本**。上一轮（c-prose-edit-affordance）只给了底色细边＋顶条，还差「编辑框」的工具栏体感。

**范围界定（重要）**：加粗/斜体等**格式按钮不做**——纯文本存储下它们无法落库（保存即丢、AI 提示词/预览/下载全链都要跟着改存储），做了就是骗人。工具栏只收纯文本语义下真实生效的动作。

## What Changes

- **编辑框成形**：编辑态顶条与正文区合为一个「编辑框」（同底色、外框连体、上圆角条＋下圆角内容区），视觉上是一个完整控件而非两条独立元素。
- **工具箱**：顶条左侧「撤销 / 重做」图标按钮（真实链路：TipTap history；无步可撤/可重时置灰），右侧保留「正在编辑正文 · N 字」「写完自动保存」「完成」。
- **不做格式按钮**（加粗/斜体/标题）——纯文本存储下的假按钮；真格式需另立「富文本存储」立项（影响 AI 提示词、预览、下载、备份）。

**非目标**：富文本存储；Markdown 语法；工具栏可配置。
