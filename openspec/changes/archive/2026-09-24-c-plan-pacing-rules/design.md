## Context

拆章链路（`chapters/ai_plan.py`）与拆卷链路（`volumes/ai_plan.py`）已上线：模板放 `prompts/*.prompt`（`<<key>>` 占位符、`_render` 替换、无缓存现读盘），素材块 Python 装配，输出 JSON 过 sanitizer（字段/长度/闭集硬校验）＋失败重试一次＋降级纯文本。拆章素材块顺序 ①进场→…→⑧上一章一行（`_blocks_chapter`），已拆章回喂带 `plot_stage`（六档闭集），配额块有末章/剩余/排满/未设四态——但全程无位置信息。`volume_rules.prompt` 是七条硬规则＋体检判据的文本单源，Python 按「【体检判据】」锚点切两段分喂 expand/check 两端点，配逐字对拍测试。提示词工程师评审（本 change 立项前）已定稿各片段成稿文案与措辞纪律，见 specs 引用的片段全文。

## Goals / Non-Goals

**Goals:**
- 位置密度规则可按章号/卷号精确生效：全书第 1 章、第 2–3 章、各卷第 1 章三处加压，其余章不受扰。
- 主体模板与评分契约零漂移：只加占位符与片段文件，既有逐字对拍测试面不扩大。
- 节奏长期失衡可被看见：连续平章出提醒、排满未到高潮出提示，都不拦、不代笔、不烧 token。

**Non-Goals:**
- 不加任何新必填字段、不动四维评分与 sanitizer 硬校验、不动门禁分档（生成仍 PRO）。
- 不做「每 3–5 章一坎」的章节层规则（模型看不见全书历史，无法执行）；由卷纲体检「对节奏」组＋本地提醒承载。
- 不建离线 eval 框架全套（12 固件＋kappa 校准等）：先落确定性哨兵＋人工抽检，eval 体系留第二轮。
- 不做提示词热更新/覆盖层（已记账 todo.md，与本 change 解耦）。

## Decisions

1. **「数据行＋条件片段」双轨，不只在素材里给位置让模型自己套规则**——haiku 级模型不会从「全书第 1 章」这行数据自行推导出「禁铺垫开场」；也不做整模板按位置分叉（`chapter_split_ch1.prompt` 整份复制），那会让十条硬规则＋评分契约（sanitizer 的对拍基准）裂成多份。落点：`_blocks_chapter` 首插 `【本章位置】`数据行；`chapter_split.prompt` 加 `<<position_rules>>` 占位符一行；片段独立四文件（`pos_ch1`/`pos_golden3`/`pos_vol_start`/`volume_pos_first`）。片段标题写在片段文件里、模板不写——空片段必须渲染为空串。

2. **选择器为纯函数，输入归约为位置角色**——代码不拿裸卷号/章号拼文件名，先把库状态归约成 `ch1`/`golden3`/`vol_start` 三个角色（互斥关系由判定式保证：全局章号 1 → ch1；2–3 → golden3；卷内第 1 章且全局 ≠1 → vol_start）。全局章号＝前面各卷已拆章数（滤 `ghost_of`，`chapter_repo.list_by_project` 现成）＋卷内序号。只依赖入参（全局章号、卷内章号、卷长、是否末章），不读可变状态——重拆同章稳定产出同片段。替代方案「在素材里给位置数据、规则写死主体」被否：主体会膨胀且规则永远在场（卷中普通章也背着三条用不上的位置规则）。

3. **片段措辞纪律（评审定稿）**——一行一动作且绑定卡面既有字段（plot/obstacle/ending/stage，给模型自检面＋系统对拍面）；正例先行、否定跟随；片段内不写「如果…则…」复合条件（条件由加载机制保证为真）；优先字面可验证措辞（「钩子」→「停在新麻烦刚炸开、还没接招的地方」）。`pos_vol_start` 用「本章就让核心冲突露头」不用「最迟第 3 章」——后者是允许拖延的死文本。`pos_golden3` 第 4 条把「第 3 章小兑现」写成三卡互异轴——防共享义务把三张卡趋同。**不配整卡 few-shot**（4096 预算被三卡＋schema 占满；示例卡会被表面抄袭泄进三方向、伤 `diff.axes` 互斥契约），只用行内正反例（`diff.one_liner` 合格例/不合格例先例，约 40 tokens）。

4. **「每 3–5 章一坎」不上章节层**——模型单次调用只看得见末 12 条已拆章，对不可见历史计数是小模型最稳的失败模式。承接拆两处：卷纲体检「对节奏」组（AI 判、免费、软门禁）＋本地升档提醒（确定性判、零成本）。升档提醒触发条件收窄（末 3 条全落低三档且无升档、卷内计数、非末章且剩余 >1、末 3 条含「重要转折/高潮爆发」不触发），文案约束剧情事实（冲突推上新台阶）并让 stage 跟随事实、引用模型自己标的 stage 序列作依据——避免与「stage 选最贴一档」的既有契约打架。**判定只进素材装配，绝不进 sanitizer/重试链路**——stage 标错一章就触发重抽会白烧 token 且掩盖真问题。

5. **高潮义务主场放卷末（`ending`）字段、不放 `summary`**——summary ≤80 字的契约是「这一卷讲什么」，塞「高潮＋位置」要吃 20–30 字且两类信息混读；ending 在结构上就是卷末交代的前奏（goal 并卷末先例），「高潮：X 事件（后段）；随后 Y 收束」25–40 字装得下。规则 8 进 `volume_rules.prompt`（锚点前），体检判据「对节奏」独立成组（不塞「对主线」，锚点切分与对拍面不变形）。`volume_expand.prompt` 的首卷片段走独立 `<<volume_pos_rules>>` 占位符、SHALL NOT 拼进 `<<hard_rules>>`——保 rules 单源、锚点切分、对拍测试三件套；`volume_options` 不注入任何节奏片段（三套互斥优先于节奏，options 温度 0.7 保发散，节奏由 expand 统一执行并显式覆盖慢热走法）。

6. **排满未到高潮＝warnings 软提示**——复用出卡响应既有 `warnings`（越纲对拍警告的渲染链路与 warn 语气），不新增 UI 状态、不阻断、不自动重拆：作者有权写刻意的过渡卷。替代方案「体检端点新增第四组本地判定」被否：跨端点重复装配、且拆章时点的即时性更好。

## Risks / Trade-offs

- **既有对拍/快照测试会被位置行打穿**：渲染产物首行多出「【本章位置】…」后，凡钉渲染产物的逐字对拍须按位置归一化（剥首行再比）或按 4 个位置各出快照——tasks 里作为独立条目先行，不先定 CI 假红。
- **ch1 钩子压力 vs 三卡互斥的趋同风险**：三卡都被要求「章末大钩」时 ending 可能趋同。缓解：哨兵指标盯 `diff.one_liner` 互换通过率（人工抽检 20 例）；若劣化，回退手是把片段第 3 条收窄为「ending 停在没解决处」（与主体规则 4 合流），差异化交还 `diff.axes`——单变量回滚，禁止一次改两处再测。
- **golden3 的「困难比上一章更狠」依赖【上一章一行】块**：该块在素材 ⑧，片段引用它属跨块引用，模型可及（同包内）；若哨兵显示执行率低，降级措辞为「写清代价或风险具体高在哪」。
- **全局章号的语义漂移**：中途插卷/回改拆章会移动全局章号，同一章的片段可能变化——这是**期望行为**（位置决定密度），但在「回改第 2 章再重拆」场景下提醒行/片段可能与上次不同；选择器幂等性只保证「同状态同输出」，不保证「跨状态同输出」，测试口径按此写。
- **效果归因**：提示词规则能保证密度与位置（冲突进场够早、反转够密、高潮有着落），「爽」的最后一公里仍在正文层；哨兵指标验证的是「不平」的结构性收敛，不是读者留存。
