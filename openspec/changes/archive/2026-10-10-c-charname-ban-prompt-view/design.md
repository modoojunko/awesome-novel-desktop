# design — c-charname-ban-prompt-view

三轮拍板轨迹（均按用户原话钉口径）：

## 拍板 1：系统段不下发不展示

第一版回显把 system＋user 都带回前端，被打回。系统段＝提示词资产：**响应只带用户段**，
且不是前端藏一下——后端就不放进响应（泄漏守卫钉：测试断言实发 system 不出现在响应
任何位置）。产出字段说明与 JSON 骨架属于「返回什么格式」，同属资产，随第三轮拍板
整体归系统段。

## 拍板 2：交互＝提示词先行编辑流（对齐生成正文弹窗）

「先出稿再附带回显」被打回。定形：

```
点起草 → preview（只渲染，不调模型不计费，秒出）
      → 弹窗 textarea 展示渲染稿（可改）
      → 点「生成」→ body.prompt 编辑稿逐字下发（空白回落渲染稿）
      → 结果段：换一个（沿当前编辑稿重跑）／采纳 · 写入／查看本次提示词（回显）
```

- D9 缓存语义保留：已出过稿重开同一行＝直接看缓存结果，不回编辑段。
- 失败留在编辑段（可改可重试），不弹空结果。
- 立主角与一键立卡同款（同一端点，后端按卡角色分派模板）。

## 拍板 3：产出格式说明挪系统段

用户改提示词时不该看到「返回什么格式」。字段说明＋JSON 骨架从 user 段挪 system
【输出契约】；user 段留【空格键位】＋写作口径＋新拟名禁令。技术点：系统段不经
`str.format`，JSON 骨架可写单花括号（`{"` 不触发 sync.py 占位符正则
`\{([a-z_]\w*)\}`）；user 段骨架原本的双花括号转义随迁移消失。

## 命名禁令口径

- 硬禁：16 字表（晚晴墨默苟满砚知景微之舟念国建梅）逐字列出＋同音同算（同音不同字、
  连声调不同都算违规）。
- 软口径：禁烂俗文学腔（不堆「夜雪月冷凤龙殇离颜」滥调字、不用「慕容上官南宫」式
  装腔复姓、不起四字仙侠名）＋「往真人上起」。
- **作者已写名字豁免**：简介或卡上已写的照抄原文，禁令首条明写「不受本节约束」——
  禁令只管 AI 新拟的名字与别名。
- **示例名自证合规**：cast_draw 输出示例 孟舟白（含禁字「舟」）→ 郑铁栓。示例是
  最强 few-shot，改禁令必须同批改示例名。

## 判例

- 跨仓模板漂移：拆两仓的 change 模板半边先落提示词仓 main → C端本地带源跑测试
  KeyError:'current'（format 缺占位符）。KeyError 词出现在 prompt.format 帧＝模板
  多了占位符，不是 dict bug；CI 缺源跳过＝面上假绿（#779 合入收口那 10 个存量红）。
- 模板内容挪层（user→system）时，行为测试里钉措辞的断言要跟着改层
  （test_protagonist_path_keeps_hero_template 的「主角的名字」判别短语改读 system）。
- prompts 仓 CI gates 红＝仓级 Actions 基建存量（job 零步骤秒挂，首跑起未绿）；
  本地闸门才是真证据。
