# Proposal: c-prompt-pack-onboard-modal

## Why

提示词包（用户可见名词「写作能力」）自 v0.28.1 起硬切随 CDN 分发，但首装与更新两条链
对作家不可见：首装登录后装包过程全静默（四态卡按设计「获取中不渲染」，只在 AI 助手右
栏出现），一旦登录时刻的同步被并发锁吞掉或瞬时失败（S端 冷启动/CDN 抖动），没有任何
提示、没有近期自动重试，作家不知道要去哪里补救（2026-10-07 用户实测定诊）；版本更新
则只有手动点账号菜单小字行的「检查」才会发生。需要把「获取写作能力」变成作家看得见、
走得到的显式流程（用户 2026-10-07 拍板：首装弹窗引导＋回作品页检测更新确认制）。

## What Changes

- **首装引导弹窗（自动开始）**：登录后落地「我的作品」页时检测本地包，未装→弹窗告知
  将自动下载安装，弹窗内展示分步进度（检查版本/下载/校验安装）；**进度期弹窗锁定**
  （Esc/遮罩/X 全不可关、文案明说「期间不能关闭此窗口＋预计耗时」），完成提示可关闭，
  失败解锁给重试（右栏四态卡继续作工作台内兜底）。
- **更新确认制**：每次回到「我的作品」页静默探测 CDN 版本（新「只探测不安装」本地端
  点）；有新版本→复用同一弹窗提示（当前 vN → 最新 vM），用户确认后复用下载安装进度，
  完成提示可关闭。已装包完好时启动/登录钩子不自动换版（现状语义显式化）；min_client
  跳过与无更新保持全静默。
- **账号菜单入口升级**：右上角账号面板 foot 里的小字「写作能力 vX [检查]」行退役，
  迁为「数据」组内与「模型配置 · API Key」并行的完整菜单项（状态随行：已就绪 vX／未
  就绪／有新版本），点击打开同一弹窗（手动检查入口）；诊断复制并入弹窗失败态。
- **触发链修复（定诊结论同批落地）**：同步器在途时新触发不再被吞（pending 重跑一
  次）；未登录时启动钩子不再空跑（无 token 换钥必 401 且占锁放大首装竞态）；状态快照
  暴露 `step` 分步进度供弹窗消费。
- **存量 UI 收口**：右栏四态卡保留为工作台内兜底；`prompts_missing` 兜底文案按「已登
  录失败」改口径（指向菜单「写作能力」重新获取）；AcctMenu 旧 `am-pack` 小行样式退役。

## Capabilities

### New Capabilities

（无——全部落在既有 capability 上）

### Modified Capabilities

- `prompt-pack-delivery`：
  - MODIFIED「提示词包获取与安装（C端）」——首启装包从「全静默」改为「弹窗引导＋进度
    可见（下载仍后台不阻塞）」；新增「版本探测端点（只探测不安装）」与「更新经用户确
    认后安装」语义；同步触发可重入（pending 重跑）＋未登录不空跑；状态快照含分步进度。
  - ADDED「写作能力引导弹窗（首装/更新/手动）」——同一弹窗三模式的状态机与出口，含
    「我的作品」页探测触发与账号菜单「数据」组入口。
- `design-system`：弹窗为新 UI 形态，登记 modal 三模式文案与进度行（原型先行：
  prototypes 书架原型＋ADJUSTMENTS.md＋design-vocab.mjs 新词两端同批——具体清单实施
  时按 design 定）。

## Impact

- **后端**：`client/backend/prompt_pack/sync.py`（step 状态、`probe_latest()`、
  `trigger_sync` pending 重跑、未登录早退）；`prompt_pack/router.py` 新 GET
  `/api/prompt-pack/probe`；`auth_local/service.py` 钩子不变（早退条件已满足「完好不
  换版」）。
- **前端**：新 `PromptPackModal`（壳层单点挂载＋CustomEvent 开启，沿用
  legacy-migrate:open 先例）；`NovelListPage` 挂载探测；`AcctMenu` 数据组新项＋foot 行
  退役；`PromptPackCard` 文案微调；`licenseCache` PackStatus 扩 `step`。
- **e2e**：强制包模式假 CDN 夹具扩「首装弹窗/更新确认/菜单入口」场景；存量 AcctMenu
  pack 行断言改造。
- **不受影响**：S端 发钥契约、publish.py 发布链、loader 解析序与本地加密布局、四道校验
  链、`/auth/verify` 挂载面（`prompt_pack` 字段自然带上 step）。

## 非目标

- 不改包格式/加密/验签/发布链；不做强制更新（min_pack_version 召回闸维持既有语义）；
- 不做后台定时轮询更新（探测只在回到作品页/打开弹窗时发生）；
- 右栏四态卡与 BLOCK_TEXT 引导机制保留（弹窗是主引导，卡是工作台内兜底）；
- 不动「模型配置 · API Key」项本身。
