# workbench-appbar-resume — 设计要点

## 目标形态（以原型为准）

`docs/design-c/prototypes/book.html` 顶栏段（ADJUSTMENTS #23/#26）：

```
logo（即返回·title「返回我的小说」）｜书名（双击改名）｜题材胶囊｜
当前主线：第 N 章＋题 ｜草稿徽 ｜第X卷 · 已归档/总章 ｜进度条 ｜续写 ｜账户胶囊（档位徽）
```

## 关键取舍

- **返回入口收敛到 logo**：原型口径。原「← 我的小说」链接退役，牺牲少量可发现性换单行空间（logo 恒在，点它即回书架）。
- **免费态转化位**：free-hint 与顶栏升级钮不再占顶栏；档位徽承担状态告知，升级入口留在右栏 locked 卡与本书偏好弹窗——可达路径不减少，但顶栏不再直接劝转化（原型即如此）。
- **bar-here 端点口径**：本次＝「上次写作会话 → 最新归档章 → 首章」。storyline.html 原型的拟定/待写 frontier 口径（含拟定排队与「只能从主线末端开写」的门禁）**不在本次范围**，待主线状态机立项后切换（ADJUSTMENTS #26 已划界）。
- **续写会话是设备本机偏好**：localStorage（`pref.book.{pid}.last_write`），与「本书偏好」（字号/行距/归档 AI 摘要）同族；不入库、不上传、不随导出包（应用侧历史不随包，见导出契约）。
- **草稿徽**：目标章有正文且未归档＝「草稿」。款式收编 storyline 的 `.tag/.tag-live` 但改名 `.bh-tag/.bh-tag-live`——避让 book.html 既有 `details.cfg .tag`（摘要标签，同名异义）。
- **档位徽豁免**：行头归一把 AcctMenu 带进 `.wb` 作用域，而 `book.css` 既有 `.wb .badge { background: none }`（树徽清零防御）会吃掉档位徽底色 → 补 `.wb .appbar .badge-{accent,muted,warn}` 三态豁免（值同 `index.css`）。

## 边界与回落

| 场景 | 行为 |
|---|---|
| 会话章被删 | bar-here 与「续写」回落最新归档章 → 首章；不报错 |
| 会话章已归档 | 续写落到该章既有只读态（只读横幅/恢复编辑入口），不自动解锁写 |
| 空章 / 内容不足一屏 | 恢复为 no-op（滚动比例 0） |
| 恢复后继续写 | 单次守卫（appliedResumeRef）：信号只应用一次，之后不干预作者滚动/输入 |
| 切章加载中 | rAF 轮询等内容就绪（上限 2s），超时标记放弃防重入 |
