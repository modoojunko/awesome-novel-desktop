# client-update Delta

## ADDED Requirements

### Requirement: 版本号常驻展示（窗口底部状态条）

C端 SHALL 在应用窗口底部常驻一条细状态条：右对齐 muted 小字展示当前版本，登录态、未登录态、工作台内均 MUST 呈现（三态无盲区），且不随路由切换消失、不提供交互。唯一豁免：免登录营销落地页（`/`）不呈现状态条——该页保留其自带品牌页脚（已含版本行），属营销页非应用态。版本文案口径：正式构建 MUST 显示「v{版本号}」；dev 构建 MUST 显示「开发版 dev」而 MUST NOT 渲染为「vdev」；版本获取失败时 MUST 静默降级显示「版本未知」，MUST NOT 弹出任何错误提示。书架屏既有页脚版权行 SHALL 并入状态条展示；应用 MUST NOT 在状态条之外再呈现第二条底部常驻条。顶栏（常规与工作台两变体）MUST NOT 新增版本元素。

#### Scenario: 登录态书架常驻可见

- **WHEN** 已登录用户进入书架屏
- **THEN** 窗口底部出现状态条，右对齐文本含当前版本号（如「v0.15.1」）

#### Scenario: 未登录态仍覆盖

- **WHEN** 未登录用户停留在登录页或书架
- **THEN** 状态条仍呈现且含当前版本号，顶栏无任何版本元素；营销落地页（`/`）不呈现状态条

#### Scenario: 工作台内仍覆盖

- **WHEN** 已登录用户进入某本书的工作台
- **THEN** 状态条仍呈现且含当前版本号

#### Scenario: dev 构建文案

- **WHEN** 应用以 dev 构建运行（版本自报为 `dev`）
- **THEN** 状态条显示「开发版 dev」，不出现「vdev」

#### Scenario: 获取失败静默降级

- **WHEN** 版本获取失败
- **THEN** 状态条显示「版本未知」，且不出现任何错误提示（toast/弹窗）

#### Scenario: 书架页脚并入状态条

- **WHEN** 用户查看书架屏底部
- **THEN** 原页脚版权信息在状态条内呈现，窗口底部只有这一条常驻条

### Requirement: 设置弹窗版本行

全局偏好弹窗与工作台偏好弹窗 SHALL 各自在底部以 muted 小字展示当前版本行，文案口径与状态条一致（正式版 / 「开发版 dev」 / 失败「版本未知」）。版本获取 SHALL 静默且不阻塞弹窗呈现，SHALL 复用应用级版本缓存，MUST NOT 因打开弹窗发出额外的未缓存请求；失败时 MUST NOT 弹出错误提示。工作台偏好弹窗 MUST NOT 新增账号身份展示（用户名）——其既有账号行（套餐文案与升级入口）为既有功能，保持不动。

#### Scenario: 全局偏好弹窗含版本行

- **WHEN** 用户打开全局偏好弹窗
- **THEN** 弹窗底部出现版本行，文本含当前版本号

#### Scenario: 工作台偏好弹窗含版本行且不新增用户名

- **WHEN** 用户在工作台内打开本书偏好弹窗
- **THEN** 弹窗底部出现版本行，且不新增用户名展示（弹窗可保留其既有套餐文案与升级入口）

#### Scenario: 弹窗版本行失败静默

- **WHEN** 版本获取失败时打开任一偏好弹窗
- **THEN** 版本行显示「版本未知」，不出现错误提示

## MODIFIED Requirements

### Requirement: 更新提示条交互

检测判定有更新时，C端 MUST 在所有屏（含工作台沉浸模式）的全局层呈现一条 info 语气提示条：说明文案含新版本号与本机当前版本号的对照（「发现新版本 v{latest}（当前 v{current}）」，`notes` 摘要有值时附一句更新说明），并附动词主按钮「去下载」与次级动作「查看更新内容」。点击「去下载」MUST 唤起系统浏览器直达官网下载页；点击「查看更新内容」MUST 唤起系统浏览器打开该版本的更新说明页（URL 由烘入下载域拼接版本号构造，不依赖额外线上字段）。提示条 MUST 可关闭：关闭后对该版本不再出现，后续新版本再判定为有更新时重新出现。无更新、检测失败或 dev 环境时 MUST NOT 呈现提示条。对照文案中的当前版本号直接取自同一次检测响应，MUST NOT 发出额外请求；当前版本号异常缺失时退回仅含新版本号的文案。

#### Scenario: 有更新时提示并直达下载页

- **WHEN** 线上最新版 `0.13` 高于本机 `0.11` 且检测成功
- **THEN** 所有屏顶部出现 info 提示条（文案为「发现新版本 v0.13（当前 v0.11）」，有 `notes` 时含一句更新说明）
- **WHEN** 用户点击「去下载」
- **THEN** 系统浏览器打开官网下载页，应用内不嵌套加载外部页面

#### Scenario: 查看新版本变化

- **WHEN** 提示条呈现且用户点击次级动作「查看更新内容」
- **THEN** 系统浏览器打开该版本的更新说明页（`download/v<VER>/notes.html`），应用内不嵌套加载外部页面

#### Scenario: 关闭后按版本记忆

- **WHEN** 用户对 `v0.13` 的提示条点击关闭，应用重启后线上仍为 `0.13`
- **THEN** 提示条不再出现；待线上出现 `0.14` 时提示条重新出现

#### Scenario: 无更新时不打扰

- **WHEN** 检测结果为无更新、失败或 dev 环境
- **THEN** 界面不出现任何更新相关元素
