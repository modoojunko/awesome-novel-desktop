# 升级发布说明（草稿 · 面向用户）

> 用途：随版本更新弹出／放进更新公告。大白话，不出现内部术语。

## 这次升级：伏笔设定大升级，请先看这一条

### 升级时会发生什么

这次更新对数据存储做了一次大整理。**安装新版后第一次打开应用时**，旧的数据文件无法在原地继续使用，应用会自动帮你做两件事：

1. **自动完整留档**：旧数据文件会被原样保存（文件名里带时间戳，比如 `novel.db.legacy-20260401-120000`），不会被删除。这是你的完整备份，万一有问题随时可以找回。
2. **提示你从备份包恢复**：应用会提示你「从备份恢复」。用你之前导出的备份包（zip 文件）一键恢复，书、章节、正文、角色、设定都会回来。

### 重要：请先导出一份备份，再升级

如果你手头还没有备份包，强烈建议**先在旧版本里做一次「备份」，把两个 zip 文件保存到安全的位置，再安装新版本**。这样升级后就能直接恢复，什么都不会丢。

- 备份入口：设置 → 备份与恢复 → 导出备份（会生成资产包和配置包两个文件，两个都要保存好）。

没有备份也能升级吗？可以。旧数据已经自动完整留档在你的数据目录里，不会丢失；但恢复起来要麻烦一些，需要联系我们协助找回。所以还是建议先备份再升级。

### 备份包里新增了什么

从这次版本起，**备份包里会包含你的伏笔设定**（之前伏笔不在备份范围内，备份恢复后伏笔会丢）。恢复备份后，伏笔会连同它们的引入章节、收束状态、优先级一起回来，并且自动挂回正确的章节。

### 伏笔功能本身的变化

- 伏笔从「一段文字」升级成了「一张台账」：每条伏笔有了编号、类型、优先级和状态，可以精确关联到某一章。
- 引入／收束的章节引用更精准了：即使章节重新编号或从备份恢复，伏笔的章节关联也会自动跟着对上。
- 个别很老的写法（比如手写的"1-1"这种章节号、不规范的优先级）会自动转换成新格式；实在认不出的章节引用会先空着，内容不会丢，你重新选一下章节即可。

### 遇到问题？

- 恢复备份时提示「备份包格式版本较高」：说明你用了更新版本应用导出的包，请先把应用升到最新版再恢复。
- 数据目录里带 `.legacy-` 的文件就是升级留档，在确认一切正常之前请不要删除它。
