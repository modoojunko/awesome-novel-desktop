# Design — 体检第五条（对照设定）

## Context

- 现状：`run_arc_ai` 只对 `draft`/`calibrate` 组装 `_arc_material`（c-arc-draft-material），`arc_check.prompt` 的输入只有书名/简介/题材 + 主线全文 + 三问；四条判据全部只看主线自身。前端 `StoryArcForm` 以 `checks.map` 动态渲染，条数不写死 → 加第五条无 UI 改动。
- 口径依据：《提示词素材给量》决策记录「卷/设定体检 = 校验型 → 设定全量（裁判手里的法典必须全）」；本文档的「逐环节给量表」把设定体检与卷体检同列。
- 零件同源：`world_summary_text(raw, None)`（含铁律红线）/`character_service.list_characters`/`build_genre_section`，与起草侧逐字同源。

## Goals / Non-Goals

**Goals:**
- 「主线里出现的势力/人物/地点是否在设定里、是否违反世界铁律、与人物档案的定位有无硬冲突」可查，且判据 name 逐字稳定（前端与 e2e 可依赖）。
- 设定为空/未填时，第五条降级为 miss＋「先补再查更准」，不编造冲突。

**Non-Goals:**
- 已拆卷清单/伏笔台账/文风设定/人物关系表进体检素材（与起草同边界；写入一半的书「主线 vs 已拆卷」的对照留待与起草侧同类问题一起拍）。
- 行内基调（tone）扩素材——单格建议不需要法典。
- 体检从「只提醒」变成拦截（判据只出 ok/warn/miss，不拦确认、不改主线字段）。

## Decisions

**D1 素材＝`_arc_material` 原样复用（draft/calibrate/check 三者同源）**：world（含铁律）/genre_section/cast 三者同取；`hard_rules` 片段也一并算出来但 `arc_check.prompt` **不引用**它——那三条是"怎么写"的约束（红线/只用已有专名/冲突以铁律为准顺势化解），体检只判断不创作，引用反而会诱导它给改写建议。Python 侧多算一次文件读取，成本可忽略。
备选：给 `_arc_material` 加 `with_rules` 开关（弃：为一个文件读取增加参数面）。

**D2 第五条判据写成「可指名」形态**：要求 note 指到具体专名或条款（「主线出现的『XX 议会』不在世界观势力里」「'死者不可复生'被这条线绕过」），而不是笼统一句「与设定有冲突」——否则作者无法据此修改；同时沿用「只提醒不否定作者」的语气约束。

**D3 空设定降级写在判据里（不是靠素材占位）**：素材空时 `_ARC_WORLD_EMPTY`/`_ARC_CAST_EMPTY` 已是指令式占位（「未填——不要为它补写、不要在产出里提到它」），第五条再明确「设定为空 → 本线 miss ＋『设定还没填，先补再查更准』」——两道一起保证「空设定照常出五条、第五条不编造」。

**D4 体检温度/输出契约不动**：判定类 0.3、`json_mode`、`operation=arc_check` 记账、`{value:{checks,summary}}` 信封均不变；仅 checks 数组多一条。

## Risks / Trade-offs

- [体检 token 上升（约 3 倍）] → 校验型口径的既定代价（决策记录），与起草/拆卷同量级；观测走既有 usage 记账。
- [模型拿第五条乱报冲突（把简介里的词当设定外专名）] → 判据限定「以设定原文为准、指名到具体专名或条款」，且只提醒；真机 A/B 抽查一次产出是否指名合理。
- [口径回退风险：起草侧「体检不组装素材」的断言/条款残留] → 本 change 同批翻转该断言并 MODIFIED 该条款，测试锁死。

## Migration Plan

纯后端改动，无存储/接口形状变化，随常规发版。回滚＝回退该 commit（prompt 与 gate 同批）。本地/演示栈需重建 client-backend 镜像才生效。

## Open Questions

- 写到一半的书，体检要不要也对照「已拆卷清单」（防主线与既定卷打架）——与起草侧同一问题，建议将来一并拍。
