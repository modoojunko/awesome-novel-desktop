## ADDED Requirements

### Requirement: 大模型出网调用独立落 llm.log

C端 三类大模型出网调用——生成调用（AIClient）、连接探针（测试连接／拉取模型清单）、朱雀检测——SHALL 每次调用恰留一行日志，且该行 SHALL 同时落当日按天日志（`app.log`）与专项档 `llm.log`（双写：求诊主档不缺行，专项档供 AI 问题直查）。行 SHALL 含：动作类型、供应商标识、供应商主机与请求路径、模型 id（如适用）、上游 HTTP 状态码（请求未完成记 0）、耗时（毫秒）与结果分类（成功／认证失败／限流／超时／网络错误等）；失败的行 SHALL 升级为告警级别并带错误摘要（截断）。专项档 SHALL 与按天日志同轮转同保留参数（按本地自然日、保留 5 天）、有独立体积护栏（同型消息限速），其初始化与关闭（`AINOVEL_LOG_OFF`）语义 SHALL 与按天日志单源。隐私红线：API Key、请求或响应正文全文、URL query 串 MUST NOT 落日志——生成调用正文只记 token／字符数，朱雀检测正文只记字符数，探针请求路径只取路径段。

#### Scenario: 连接探针认证失败可定诊
- **WHEN** 用户点「测试连接」或 Key 失焦触发清单探针，上游端点返回 401/403
- **THEN** 当日 `llm.log` 存在该探针的告警行：探针类型、供应商、主机、路径、上游状态码 401、耗时与认证失败分类，且行中无 API Key

#### Scenario: 探针超时或网络失败留痕
- **WHEN** 探针请求因超时或连接失败未完成
- **THEN** `llm.log` 存在该探针的告警行：状态码 0 与超时／网络错误分类、主机与耗时

#### Scenario: 朱雀检测正文不落日志
- **WHEN** 整章正文送朱雀 AIGC 检测（成功或失败）
- **THEN** 该调用恰一行留痕，行中只出现正文字符数（chars），不出现正文内容

#### Scenario: 双写求诊主档
- **WHEN** 任意大模型出网调用留痕
- **THEN** 同一行同时出现在 `llm.log` 与当日 `app.log`，app.log 侧既有 AI 留痕行格式不回退

#### Scenario: 专项档轮转与保留同口径
- **WHEN** `llm.log` 跨过本地 0 点或历史文件超过保留窗口
- **THEN** 与 `app.log` 同参轮转（每天一个文件）并只保留最近 5 天

#### Scenario: 日志整体关闭
- **WHEN** 环境设 `AINOVEL_LOG_OFF=1`
- **THEN** 专项档 handler 同样不挂载，测试与脚本零文件副作用
