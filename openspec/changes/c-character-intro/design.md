# Design: c-character-intro（章纲人物精盘）

## Goals / Non-Goals

- Goals：spec（chapter-cast-review）钉死的全部行为；决策链路**零新存储**——落账只走既有章纲保存通道（`apply_chapter_data` 的 characters 通道），配额从聚合派生。
- Non-Goals：不整合 plot_sim（推演）通道的精盘入口（殊途同归，推演侧不动）；不做 todo 章层②③④；不做角色表侧「归档生长/批量识别」（另一 change）；不做拆章卡 cast 申报的机判增强（照旧只对拍）。

## Decisions

1. **精盘输入＝作者已定的剧情（剧情条目），SHALL NOT 用 AI 推演剧情盘人**——D20 的核心教训（真书演练「牵强」事故）。条目为空退化整章一行（梗概+挑战+章末落点）。
2. **呈现载体＝弹窗（CastReviewModal），不是名单区行内**。理由：#502 后名单区只剩 chips+textarea，无段级行可挂逐段三分类与三选一；弹窗复用既有体系（`pk-corner`/notice/locked 全现成）。与 D20「行内三选一」的差异在此登记：决策仍长在章纲页，落账结果（chips 更新+没卡标记）仍体现在名单区。备选「名单区扩展段级行」被拒——把盘点表塞进章纲表单会重演「字段越养越多」的老路（#502 刚瘦过身）。
3. **门控分档**：盘点＝免费（`require_novel_model`，照 ai-selfcheck 只读例外先例——盘点是决策支持且常态输出「零新增」，收费会把常输出变成付费空转）；抽卡＝PRO（`require_ai_access`，生成类先例 ai-directions/plot ai-draw）。免费锁定＝**按钮级**（缺口卡内「抽卡选人」禁点＋按钮外 PRO 标＋升级出口＋「自己填一个」全免费，照 onPlotDraw `disabled={archived || locked}`＋upgrade-exit 先例）；SHALL NOT 向免费档展示任何 AI 生成的卡面内容（评审收口：v1「免费锁定假卡场景」删除——免费态不调生成端点，假卡即门控自相矛盾）。备选「全 PRO」被拒如上；备选「全免费」被拒——生成类必须过统一付费门，避免第二个免费生成入口。
4. **提案卡三维评分与差异轴闭集**：合不合适（只看缺的人+缺人行）／差别在哪（只看人设句，与老角色比）／好不好落地（只看出场退场计划）；≥2 项第一=S（三维 3 个第一名、至多一张 S）、1 项第一=A、0 项第一=B（二轮评审修正：原「≥3=S」需横扫三维、数学上不可达，稿面分布不可复现）；`_grades` 阈值按维数传参（本卡 3 维＝2、拆章 4 维＝3，共用函数不共用阈值——4 维若用 ≥2 会出两张 S）；名次唯一第一才计分（并列第一不计该维）入 spec/模板 ranks 声明/表驱动测试。差异轴闭集＝身份／关系／功能（人物原型的三个结构位）。备选沿用剧情四维（反转/递增/推进/拉力）被拒——语义不适用人物卡。
5. **落账＝申报页两出口＋前端表单合并＋既有保存链**（评审收口，替代 v1「落账两拍」——零新存储约束下，先只加名单、之后行级建卡时提案字段无处可取，两拍不成立）：确认页两出口各自独立落账——「只加名单」（称呼并入 `ogForm.chars` 后**立即保存**，不等 3s 自动保存，照 handlePlotAdopt 先例合并 chars→`saveChapter(ogToPartial(...))`→成功同步 ogSnapRef 再关窗；按行去重）与「建卡并写入」（先建卡后同前）。行级没卡标记的建卡入口保留但只预填称呼。零新写入端点、零迁移；warnings 口径原样且本次落前端消费（toast/行内提示，保存/自动保存/写入三路径都消费，自动保存处 warnings 存在才打扰）。**#513 只读两态口径（二轮 4:0 定案）**：写入章纲＝显式落账不切编辑态（照「AI 帮写剧情采纳整表落库、查看态直接刷新」先例）；保存成功后同步 ogSnapRef 是**正确性要求**——否则查看态「取消」回退快照＋自动保存会把刚写入的名字删掉；编辑态落账顺带保存未保存修改（与手填+3s 自动保存终态一致，接受）；没卡标记/建卡入口查看态（.fro 只读行）与编辑态（chips）两态都承接。落账成功回盘点结果页（多缺人回程，见 spec R5）。
6. **建卡＝`POST /characters` 向后兼容扩参**（评审实勘：现端点只收 name/role，persona 会被静默丢弃；dossier 八个冻结键无「进退场」格）：`create_character` 加可选 `persona`＋`prefill`（只收 `DOSSIER_FILL_KEYS` 的 plot/background，`_clamp` 300）——映射：name←称呼、role←默认「配角」、persona←一句人设、dossier.plot←他是干什么的、dossier.background←「怎么出场：…；怎么退场（章内/本卷/常驻）：…」拼一句（**有意拍平**退场计划进文本，结构化留待「归档生长」change）；单事务不留半张卡；persona 服务端 clamp 300；prefill 白名单硬校验（只收 dossier.plot/background，非法键 400 而非静默丢——router 现状裸 dict 透传是这次要收的口）。撞 `UNIQUE(novel_id,name)` 的 409 前端回落＝「只加名单」＋提示自动挂同名卡；称呼命中某卡别名时建卡会成功（UNIQUE 只锁 name）→ 接受双身份（存量行为，`_resolve_names` 按名优先）。免费可建（先例：字段手工填写不受门控）；抽卡锁定但手填永远通——门控锁的是 AI 生成，不是人物本身。
7. **计量**：两条独立 operation（`cast_review`／`cast_draw`），记账口径照 #497/#500 先例，不与生成类混淆。
8. **`chapter_split.prompt` 规则 2 补一句**（二轮修正：chapter-plan-ai「拆章位置感知与提示词分片」钉死「主体十条硬规则零改动」——已出 MODIFIED delta 显式许可该句，钉词对拍测试同步）：「无名配角（店伙计、路人、卫兵这类只递话、只在场的过场人物）可用泛称，不算添人、不写进 cast 申报；泛称不得承担关键剧情作用——送关键消息、做关键决断、出手改局面的必须是素材里已有的具名人物；具名新人一律不添——要不要加新角色由章纲页的人物盘点决定」（以 delta 钉词源为准，设计/提案措辞同源）。措辞改后须 grep 端点对拍措辞（计划-对齐事故教训）。
9. **新提示词模板两份＝四件文件（system/user 严格分层，星月范式——用户拍板）**（提示词工程评审定稿，骨架优先于正文）：
   - **分层规则**：**系统级＝底层角色＋永久约束，一次设置全程不变——零动态内容、零占位符**（渲染后恒定，可走供应商 prompt cache）；**用户级＝每次请求动态传入**（素材/剧情条目快照/缺人行/exclude/配额/临时要求），块界用显式分隔标题 `=====【块名】=====`。调用层原生支持（`_generate(system, user_msg)`，ai_client 对 OpenAI/Anthropic 双路径透传）；**存量模板（chapter_split 等）现形制相反**（素材烧进 system、user 仅一行请求）——其分层迁移**不在本 change**，两新模板起按分层写。
   - **文件形制**：`prompts/cast_review.system.prompt`＋`prompts/cast_review.user.prompt`＋`prompts/cast_draw.system.prompt`＋`prompts/cast_draw.user.prompt`（四件）；system 件渲染后恒定，验证含「system 文件零占位符」断言。
   - **输出骨架（两模板共用原则）**：缺人字段**内联**在行对象——gap 只在 verdict=「缺一个新角色」时给对象、其余 null；idx 照抄条目编号、echo 照抄原文前 60 字（不改写不缩写）；服务端 `len(rows)==非空条目数` 时按位置对位、不等长再按 idx 对齐、无效 idx 丢行。JSON 键名英文（review：idx/echo/verdict/who/as/why/gap{need,why_not_old,suggest}/defaulted，进服务端常量单源），值用中文闭集；**cast_draw 输出骨架同款钉键**（axis/name/persona/entrance/exit_kind/exit_note/why_not_old 不输出——服务端直抄/三维名次 ranks{合不合适,差别在哪,好不好落地}/reasons{…各 ≤20 字}，退场＝三选一档＋说明两键）。骨架示例：
     `{"idx":2,"echo":"…照抄原文","verdict":"缺一个新角色","who":[],"as":"","why":"…≤30字","gap":{"need":"这段戏缺的是（≤40字）","why_not_old":"老角色为什么不行（≤40字）","suggest":"改段"}}`
     （示例行**必须覆盖全部闭集取值**——三分类三行各一值、suggest 三值各出现一次、三卡带齐三轴、退场三档列全；模型对示例值的照抄率远高于规则句；**示例须剔 why_not_old 字段**——否则「模型不输出」被照抄击穿。退化整章行取值：idx=null、echo=梗概截 60 字、gapId=chapter）。
   - `cast_review.system.prompt`（固定）：角色（章纲人物盘点员）＋【核心规则】（硬规则第 1 条钉死「只判剧情条目里作者已写的条目——不推演、不补写、不评价剧情，只判人」；**一段只判缺一个人**（缺多个只写最缺的，其余在依据短句点一句）；**空场面段**判「不起名也行」、as 留空（防硬凑路人甲）；闭集逐字值三禁（不加标点/引号/括注）；）＋【闭集定义】（三分类/suggest 逐字值三禁）＋【输入内容识别】（用户输入分四块：素材/本章剧情条目/章纲留存格/临时要求）＋【输出规则】（只输出 JSON；idx/echo 照抄；gap 内联规则；JSON 闭形不给剧情建议字段）＋【强制禁止项】（不改写剧情条目、不自创字段、输出值不带解释括号语气词；负锚：模板不得出现改法/剧情建议/评分字样）。
   - `cast_review.user.prompt`（动态四块）：`=====【素材】=====`（主线截取/人物全名单含别名/出场名单/无卡名单/配额档位行——行尾钉「配额只影响建议的分寸，不得改变三分类判定」）＋`=====【本章剧情条目】=====`（idx＋原文）＋`=====【章纲留存格】=====`＋`=====【临时要求】=====`（可空）。
   - `cast_draw.system.prompt`（固定）：人物提案设计师角色＋【核心规则】（三卡三轴互斥（批内三轴齐出）；**三维各看各的字段**（合不合适只看缺的人行｜差别在哪只看人设句｜好不好落地只看出场退场）；ranks 声明照 ai_plot 先例「从 1 连着排、不跳档、**不并列**」（源头禁并列，服务端「唯一第一才计分」降为兜底）＋全文无等级字母分数；「老角色为什么不行」**服务端直抄缺人行、模型不输出**（省 token 零漂移；直抄不 clamp，卡字段界与源界同界 ≤40）；**抽卡素材同携配额档位行**（收紧期 1–3 每章新增约束的是申报，配额行尾同钉「只影响建议分寸」）；称呼＝新名字＋【不要用这些名字】名单块（known_entities∪已出批称呼，防变体改字）；）＋【输入内容识别】（缺的人/素材/这几条路走过了/临时要求）＋【输出规则】（骨架键名；why_not_old 不输出——服务端直抄；全文无等级字母分数）＋【强制禁止项】。
   - `cast_draw.user.prompt`（动态四块）：`=====【缺的人】=====`（缺口行）＋`=====【素材】=====`（含【不要用这些名字】名单块＋配额档位行——行尾「只影响建议分寸」）＋`=====【这几条路走过了】=====`（exclude 中性禁令块，块文以决策 10 为钉词源；拼入用户级动态块，#497 先例的块位迁移至 user 侧）＋`=====【临时要求】=====`（可空）。
10. **exclude 形制自建，不共用 ExcludeItem**（评审实勘：既有 `ExcludeItem.line≤40`，人设句 ≤60 字会直接 422）：`CastExcludeItem(axis∈{身份,关系,功能}, name≤12, persona≤60)`，批 ≤9；对拍规则＝同轴且人设句相似（difflib 0.6 沿用——库内已有 ~230 字长串用 0.6 的先例）**或称呼与已出名字等值**；丢到 <2 张走既有重试阶梯，exclude 重抽不降温。**禁令块正文**（_exclude_block 先例拼 material_blocks，中性无评判）：块头「这几条路走过了（作者换一批，避开已出的人物路数）」＋已出条目行（轴｜称呼｜人设句）＋「轴照旧三张各出一张（身份／关系／功能），轴可以再用、必须再用；禁的是同一条人物路子：同一个轴上一句人设与上面是同一路人的（或换个称呼还是那个人的），不要再出。换路子要换在人身上，但仍要贴合【缺的人】——不要为了不同而不同。」（末句防为 novelty 而 novelty；「结构上不同」措辞退役——拆章语境里它＝轴不同，会被误读成禁轴）。
11. **服务端校验与重试口径**（评审收口）：三分类 verdict 出闭集丢行不改写；「演这段戏的角色」逐名对 known_entities 过滤，滤空的「老角色能演」行保留该行＋warning、不升级整批重抽（判读类不重抽，ai_plot 先例）；整批重试只认「0 条可用行/JSON 不可解析」，MAX_ATTEMPTS=3、非 exclude 触发降温；缺人行短句 clamp 不拒收；缺人行含 **suggest 预填**（∈ 加人/改段/延后，提示词强制按上下文给、不恒为加人，出界缺省「加人」）。**输入改请求体表单快照**（plot_items＋留存格＋characters，照 SelfcheckBody 先例——补 3s 自动保存未落库盲区；读库回退会让作者所见与盘点所见不一致，二轮裁决）；响应行 idx＝快照 0 基不重排，附配额现况（有名有姓计数）与 suggest；缺人行锚＝段 idx（gapId=f(idx)，跨重盘稳定）；请求体 characters 并入 known_entities/无卡名单/软提示计数（当前章按快照）。会话失效判据只盖剧情输入（条目＋留存格），落账写名字不失效（多缺人回程依赖此条）。**中文闭集四组（三分类/差异轴/怎么退场/三选一）维持人话取值（二轮裁决）**：单源常量＋前后端 parity 测试＋服务端归一化**分流＋否定护栏**：strip → 剥首尾句读 → 精确匹配 → 唯一子串命中**且命中位置前二字窗口内无否定词（{不,没,非,无,未,别,莫,不能,不必,不是,未必}——单字窗挡不住「不是加人」，二轮终审核验）**（「不加人/不是加人」不得归一成「加人」）→ 否则出界；**2 字短值（suggest/差异轴）只做精确＋剥句读、不做子串兜底**（「加人或改段」混入句宁可走缺省）；4 字退场档可子串兜底（带护栏）。出界兜底：verdict 丢行＋「这一段没判出来」行、suggest 缺省加人（**响应带 defaulted 标志，前端不打「AI 建议」标**）、axis/退场档丢卡进重试。**重试喂回**照 ai_plot 先例：喂失败原因摘要（system 前缀）＋结构性降温 0.3，不喂失败输出原文；exclude 触发判定用显式 clash 标志位（勿抄 ai_plan 的 warn 字符串嗅探）。温度/max_tokens：review 0.2/重试 0.1、draw 0.7/结构性重试 0.3/exclude 重抽 0.7 不降温、draw max_tokens 8192。

## Risks / Trade-offs

- [difflib 0.6 在人设句（≤60 字）上的误杀率未知——比 one_liner（≤20 字）长，同阈值或偏松] → 沿用「同轴且相似」双条件兜底；阈值进常量；验收批含同轴相似/异轴同词的边界样例。
- [免费盘点被高频重跑烧 tokens] → 手动触发、无自动轮询、计量独立可审计；照 ai-selfcheck 先例接受该面。
- [弹窗三段式（盘点→三选一→抽卡）状态复杂] → 会话状态提升视图层＋`drawSession` 新键 `cs-draw:{pid}:{chRef}`（排除清单 ≤9、只记最近 2–3 批、localStorage 兜刷新、「从头再来」逃生口——#497 全套先例）。
- [无卡名字越积越多成垃圾台账] → ≥2 章软提示建议建卡；不强制不清理（归档生长属另一 change）。
- [提案称呼撞已知实体（AI 误认领旧人）] → 服务端对拍丢卡计入重试；提示词同时声明「称呼必须是新名字」。

## Migration Plan

纯新增：无 schema 变更（`ChapterCharacter`/`characters` 零改动）、无存量迁移、无兼容包袱（单用户产品、尚无真实用户基线）。后端端点＋提示词先行自洽（前端未上前不调用），前端随后；单 PR 合入亦可。回滚＝撤端点＋撤右栏入口，弹窗自含无残留状态。
