# 设计：章工作台内容页签默认只读

## 口径参照

卷纲两态（VolumeOutlinePane，c-volume-view-storyline）：`form === null` 为查看态（一页纸只读），「编辑卷纲」以服务端数据初始化表单，「取消」丢弃未保存修改，「保存」回查看态。

## 章纲两态的实现取舍

- **ogForm 仍是唯一事实源**：查看态直接渲染 ogForm 的只读投影（.fro 行），编辑态渲染既有表单。两态切换只是 `ogEditing` 布尔，不引入第二份快照。
- **取消的语义＝回退最近一次落库值**：3s 静默自动保存保留（编辑态安全网，剧情区 e2e/undo 链依赖它），`ogSnapRef` 恒等于已持久化内容（保存成功与自动保存成功都写它），「取消」按快照回填 ogForm 后退出编辑态。与卷纲「取消丢未保存修改」语义对齐——只是章纲的未保存窗口是 3s。
- **查看态不是死页面**：「确认章纲」（校验+状态迁移）与「去写正文」（flush+切页签）保留在查看态 top 行——两者都是读态合法动作；缺口 chip 在查看态可点，进编辑态并滚动聚焦对应格子（复用 flashField，时序同 handleGoWrite 的 60→80ms 延迟聚焦）。
- **AI 产物自动进编辑态**：AI 起草/缺项补全的产物必须让作者过目，留在查看态等于「填了看不见」，故成功后 setOgEditing(true)。AI 帮写剧情/推演采纳走整表落库，查看态直接刷新显示，无需进编辑。
- **就绪信号换口**：e2e/helpers 的表单就绪闸门从「保存草稿可点」改「编辑章纲可见」（查看态载入完成的直接信号；载入中渲染「章纲载入中…」占位，无按钮）。

## 文风影子两态

编辑态收敛为组件内部布尔（无跨组件消费者）；查看态行复用 .ss-row 网格（k/值/理由/占位四列），新增 `.ss-row .r` 文本档。AI 建议的「采纳」是显式动作，两态都可用（采纳后查看态即时可见）。归档章「编辑影子」直接禁用（原口径是进编辑后逐控件禁用，两态下入口禁用更直白）。

## 范围裁剪

- 正文页签不加编辑门：写作画布，已有归档/排队/旧稿三套只读语义；AI 生成自动切页签聚焦、续写恢复信号都直写编辑器，加门会打断。
- 提示词页签：PromptManagementPage 内部本就「查看分段渲染 / 编辑」两态。
- 设定/角色关系/伏笔：纯只读投影；操作页签：动作卡（破坏性动作已有确认弹窗）。
