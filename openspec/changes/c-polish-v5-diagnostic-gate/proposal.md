# Change: c-polish-v5-diagnostic-gate

## Why

用户真机反馈：去AI味产物「反而不如正文生成的」。定诊（反AI案例包＋v3 资产包＋规则集证据体系，2026-10-07）：v4.4 的「近拷贝判负＋整段换骨架兜底」把*输出差异*当完成标准——健康句子也被强制重写，而重写本身就是新的 AI 指纹（案例模式 10「二修伪自然」：油腻倒装/监控动作清单/对话指标化/电报体）；信息轮次化「有能开口的人物就应当施策」是无条件施策，实测对照（番茄 305 章）证明单向加对话即「对话指标化」反噬。同时案例硬发现「同义改写实测反升 AI 词汇提及率 69.8%→88%（ACL 2025）」「句号偏置改提示词没用」。正文生成自带反AI红线、按正面靶子写，天然更干净——去AI味在干净文本上强制换稿，期望值为负。

v5 翻转为**诊断门控**：先诊断后动刀，确诊才改、没病不动、确诊为零逐字原样返回；载体转换降为条件杠杆（资格两问＋2 来回上限）并新增反向杠杆「独白归叙」；补正面靶子（句号重音位/动作链三拍）。提示词工程师评审（2026-10-07）判定初稿两处 P0（载体双杠杆绕过门控、健康选区无原样出口），已整改（P0×2＋P1×6＋P2 择优）。

## What Changes

- `awesome-novel-prompts/prompts/polish_text.prompt` v4.4 → **v5 诊断门控版**（system 层整体重写，user 层四槽位与边界标记契约不变）：
  - 第 0 步诊断（内隐）：六类病灶 A 结构红线/B 空转/C 节奏/D 伪装/E 堆叠/**F 载体错配**；逐类过到、找反证、拿不准＝不确诊；**确诊为零 → 逐字原样输出＝合格产出**（早退分支）。
  - 第 1～4 步降AI动作（按诊断结果施策，未确诊不施策，可叠加）：①挤水（可替换性检验＋保护三问，可净删至 85%）②载体定向（信息入对白：资格两问＋每处 ≤2 来回；独白归叙：去引号入叙、留最狠一两处、重影预防前置）③病句修复（碎句连缀/句长趋同打散/回合制压连贯/名词化还原/推理链拆/罐装反应句禁代笔/起手同词去重）④换骨架重写收窄为最后手段（确诊 ≥5 处且前三步全不适用；禁同义词替换）。
  - 铁律补四项裁决：人称/时态随台词转换不算改动；书级禁用词在引号内同样必改；段落例外可执行化（首段第一句与末段末句不并入相邻段）；长度分档＋叠加取最宽区间。
  - 死路两处限定：只改标点指「无任何并句/删句/句法改动」；增删换行排除碎段并入例外。
  - 正面靶子（新增）：逗号长呼吸＋句号重音位、极短段三用途、情绪有对象、感官物理前提、动作链三拍（宜换第三拍、不足不凑）；与书级「写作风格参考」冲突时以书级文风为准（禁用词与结构红线仍压过文风）。
  - 完成判定四条 → 五条：确诊项逐条对照零残留、未确诊句原样、信息零丢失、首尾即正文、**动作重影自查**；判负改「回对应步骤继续修，不整段推翻」。
  - v4.4 语义退役：近拷贝判负、四档策略栈、检查清单、「原样交回仅限全对话选区」。
- `sync.py` CURATED 元数据同步（desc/layer/note）；注释头重渲染；manifest/README 重建。
- `tests/test_polish_text_prompt.py` 全量重写为 v5 特征串断言（45/45 绿；含 system 段禁裸花括号冒烟）。
- **C端代码零改动**：占位符契约（`writing_style`/`anti_ai_rules`/`selected_text`/`surrounding_context`）与 v4.4 完全一致，`write/auxiliary.py`、`write/router.py`、前端、门禁不动。
- 明确不做（另案）：二期产物确定性 lint（移植案例 `_precheck.py` 九道判据做交付前体检＋诊断结果注入 `{diagnosis}` 槽位的完整两阶段法）；朱雀检测回路。
