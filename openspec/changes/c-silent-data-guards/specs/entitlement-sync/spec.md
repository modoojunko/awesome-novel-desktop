## ADDED Requirements

### Requirement: 权益缓存随登出与换号失效

C端 权益快照缓存与刷新节流状态 SHALL 在登出时清除；登出后重新登录（含换账号）时，首次功能判定与徽章展示 MUST 使用新会话的权益快照，SHALL NOT 沿用上一账号的缓存结果。

#### Scenario: 换账号不沿用旧权益

- **WHEN** 用户登出后以另一账号登录
- **THEN** 权益徽章与功能判定基于新账号快照；上一账号的档位不出现

#### Scenario: 同会话刷新仍走节流

- **WHEN** 同一登录会话内路由切换触发权益刷新
- **THEN** 既有节流与按路径刷新口径不变（不因本要求变成每次请求）

#### Scenario: 登出即清

- **WHEN** 用户主动登出
- **THEN** 快照缓存与节流状态被清除（不等待下一次刷新覆盖）
