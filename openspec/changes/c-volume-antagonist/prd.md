# PRD：分卷规划——对抗物、三选一抽卡与卷字段终版（c-volume-antagonist）

状态：v1.1（PM＋前端工程师＋后端架构师三路评审合并；全部 P0/P1 已拍板并落进 specs/tasks v2）
设计事实源：`docs/design-c/drafts/ai-novel-c端-整书拆纲.html`（终版）＋本 change 三份 spec delta

## 1. 背景

分卷规划上线后经四轮用户收敛（2026-09-21）暴露三个问题：
1. **卷字段多而杂**：结构模板全链零消费、整体目标与卷末一问双答、展开依据用完即弃却占库列。
2. **角色放错层**：规划期凑整列角色＝预知未来；正确语义＝角色从章节聚合。
3. **付费体验摩擦**：多字段表单不如「三选一＋确认」。

本 change 按「谁在消费」（章纲 AI／正文提示词／下一卷规划／体检）重定卷字段终版，付费入口
重构为 roguelike 三选一抽卡，伏笔唯一登记处归台账。

## 2. 目标用户与价值

- **付费作家**：规划一卷＝三选一＋确认；坎（对抗物）显式化让卷与卷的递进可检查。
- **免费作家**：四问手写零门槛，答多少建多少；体检免费可用。
- **系统**：消除双写源（伏笔文本 vs 台账、卷角色行集 vs 章角色）。

## 4. 功能需求（FR 与验收标准）

### FR-1 规划入口分流
- 付费点「规划第N卷」→ 三选一抽卡弹窗（940 宽、窄屏纵排），打开即自动请求 options（busy 态）。
- 免费同一入口 → 四问手写页；AI 动作置灰带 PRO 说明；「直接创建这一卷」可用。
- 主线全景为空：生成类入口变「先补主线」指向主线设定；免费手写不受限。
- 三处「＋新增一卷」（顶栏空书卡/中栏起手卡/左栏底部）与右栏「规划第N卷」同一规划流。

### FR-2 三卡契约
- 每卡＝Q1 走向（标题）＋Q2 冲突＋Q3 坎（类型·一句话）＋Q4 卷末＋侧重轴标签；无角色行。
- 三套答案互不相同（difflib >0.6 触发重写复核一次）；侧重轴闭集枚举且互异。
- 套数 2–3；<3 套 note 呈现卡区顶部；网格自适应。
- 数据全部来自结构化出参字段。

### FR-3 选中与确认成卷
- 点卡选中（可换选）；未选时确认禁用；确认中呈「正在铺这一卷…」且不可二次提交。
- **Esc/背景关闭＝取消，不落库**（token 守卫）。
- 成功链＝expand（line=走向、antagonist 带入）→ 既有建/更卷接口一次写入 → 伏笔建议入台账（带查重）→ 关弹窗 → 落点卡。
- 四问字段以卡面为准；expand 只补卷名/章数/伏笔建议，不覆盖卡面四问。
- 自查条落库后在落点卡以可关闭提示呈现。

### FR-4 换 3 套
- 重调 options（重试温度档）、清空选中；PRO 限定。

### FR-5 抽卡↔手写互切
- 双向切换保留四问已答内容；手写已答作为 options 约束素材（作家答过的不被改写）。

### FR-6 免费手写创建
- 答多少建多少；卷名空兜底「第N卷」；不触发 AI、不写 hooks；落点卡承接。

### FR-7 添加卷退役
- AddVolumeModal 退役；三处入口接规划流（免费＝四问页）；初始章数字段退役。

### FR-8 卷纲四问一页纸
- 查看态无折叠块：进场（只读）→四问四行→角色聚合→伏笔指引行→（节点有值才显）→留到写的时候→进度线。
- 编辑态同骨架：1 主旨→2 冲突→3 坎→4 卷末→卷名/章数→节点；保存必填主旨+冲突；脏守卫。
- 旧 goal 非空读侧并入卷末尾句显示。

### FR-9 聚合角色只读视图
- 卷角色＝卷下各章章纲 characters 合集＋主角置顶＋坎（人物型）标反派；只读；空态「还没有章——写到谁，这里就有谁」。

### FR-10 伏笔台账建议
- 确认成卷/手写保存时经既有 hooks 接口入册（带编号与计划收束卷）；入册前与 active 台账**查重**，重复不入册并提示对齐编号；失败不回滚卷、留「补登记」入口；卷表 plants/reveals 停写。

### FR-11 体检对抗物判据
- 「对主线」组三判据：明确／较上一卷递进／卷末有了结；素材含上卷与本卷对抗物（首卷略上卷行）；未填坎＝warn 不拦；玄幻/都市带 boss 台阶默认提示；免费只读；模型未配给引导不 500。

### FR-12 字段退役
- `template_name/plan_line/goal/volume_cast_members/plants/reveals` 停读停写；PUT 拒收、GET 不回；不迁移不清理。

## 5. 非功能（NFR）

- options 首卡 P75 ≤20s；确认链 P75 ≤25s 且有进度指示；聚合角色查询 ≤200ms（≤200 章）。
- 确认可取消且无半写状态；hooks 登记失败有补偿路径。
- 文案门禁：全链「四个问题」统一；grep 断言无「五个问题」「角色一问」残留、无内部术语。
- 无障碍：弹窗焦点圈、Esc、选中卡 aria、busy aria-live。
- 回归门禁按 tasks 6.2 全量。

## 6. 边界与异常

| 场景 | 行为 |
|---|---|
| 主线空 | 生成类变「先补主线」；手写与直接创建不受限 |
| 模型未配 | 抽卡弹窗引导态（去配置＋转手写）；体检引导文案；不 500 |
| options 失败/超时 | 重试一次（降温）→ error 态＋「重试/转手写」；计量 `*_fail` |
| expand/建卷/hooks 失败 | 保留选中与卡片、toast 可重试；hooks 单独补登记 |
| 套数=2 | note 说明＋两卡布局 |
| 确认中关闭 | 取消不落库 |
| 伏笔建议与台账重复 | 不入册＋提示对齐编号 |
| 旧数据 | goal 并尾句显示；template/plan_line/cast 行集忽略不报错 |

## 7. 埋点与度量

本地事件表（可关）：`plan_entry_open{tier}` → `pick_drawn/redraw/select/confirm_ok|fail` /
`desk_manual_create/expand` → `volume_saved` → `first_chapter_in_vol`；辅助 `check_run{warn}`、
`hooks_registered{dupe_skipped}`。
上线 60 天目标：抽卡→确认转化 ≥60%；场均换抽 ≤1.5；确认→当日排第一章 ≥50%；坎填写率 ≥80%；
伏笔建议入册率 ≥70%、重复拦截命中 ≥90%。

## 8. 风险

| 风险 | 缓解 |
|---|---|
| options+expand 双跳延迟/成本 | 确认链只跑 expand；options 结果会话内复用 |
| 三套趋同 | difflib 复核＋字段上限＋降温重试 |
| 台账污染 | 入册查重＋可否决（重复提示） |
| 确认误触 | 选中态门槛＋不可二次提交＋可取消 |
| spec 漂移 | P0-3 已修；开工前 validate --strict 绿为门 |
