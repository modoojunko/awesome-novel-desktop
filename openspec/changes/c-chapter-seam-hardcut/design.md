## Context

真书实测（《我在夜晚打吸血鬼》4 章，novel-dev.db）两个断章病灶：

1. **章首接不上**：`build_chapter_context`（write/chapter_writer.py:920-933）只在上一章章纲字段全空时才回退取上章正文末 500 字；常规路径（章纲有概要/必变/落点）下上一章正文**完全不进提示词**。模型自创章首模板——第 3、4 章开头逐字同款「血腥味还没散。」氛围句重开场景。第 1→2 章接得好（「枪口还对着他」）纯因该章落点写得细，属运气不是机制。
2. **章末断不开**：`chapter_split.prompt:8`（拆章规则 4）钉「局面未定处自然断开」＋禁「神秘登场」；`write_chapter.prompt` 输出契约第 2 条禁新增事件；`chapter_selfcheck.prompt:28` 拉力维同口径。三面堵死后模型只能定格收章：第 2 章末句「局面没定。」就是拆章落点原文尾句「局面未定」的复述。作者要的形态是「解决问题、转身要走、一声『哪里走！』即止」的硬切。

该哲学是 09-24 c-chapter-ending-natural（#490）拍板的「自然断点 vs 硬造悬念钩」。本 change 按用户拍板**收窄而非推翻**：禁凭空新谜团/异象信物保留，断章标准升级为「下一拍要砸下来的一瞬硬切」。

## Goal / Non-Goals

- Goal：章首接住上一章实际文本的下一拍；章末硬切在动作/台词/声响上；拆章产出可硬切的落点；自检口径对齐；润色通道同源。
- Non-Goals：不动语义化前情（概要/必变/落点）的来源与优先级；不动进场派生与自检衔接组比对逻辑；不动 `chapter_plot_draw.prompt` 规则 9（章中条目不提前揭底，与断章无冲突）；不引入生成后重写首段/末段的二轮调用（第三刀兜底，真机验完再议）。唯一语义变化：旧「章纲全空回退正文末段摘要」由尾块承载替代（见 D1 回退块化），语义化前情本身不动。

## Decisions

### D1. 上章结尾原文＝独立常驻块，与语义前情分工（章首）

- ctx 新字段 `previous_tail: str`；`build_chapter_context` 在既有 `prev_ref` 取数处（chapter_writer.py:924-933 附近）读 `prev.get("prose")`，经 `_clip_tail_paragraphs(text, PREV_TAIL_MAX_CHARS=800)` 裁剪。
- 裁剪：按 `\n` 分段（正文契约单换行分段），从末段向前累加至 ≤800 字；单独一段超限时取该段尾部并回退到句边界（。！？」……）起头，保证不以残句开头。
- **回退块化（防重复＋旧书得接点）**：上一章有正文即注入（语义化前情生效与否无关）。章纲全空的旧回退路径（`previous_chapter_recap=prose[-500:]`，硬截残句同款病）**退役**：回退场景下由「上章结尾（原文）」块直接承载正文末段（≤800 字、句边界裁剪），语义前情段缺席——同一段文本只出现一处，且旧书因此同样吃到「章首接点」铁律。第一章/上章无正文：块自然缺席。
- 渲染：`render_previous_tail(tail)` 单源函数，两路同字：
  - `to_user_material`：`## 上章结尾（原文）`，插在「## 前文回顾」之后、「## 故事状态（截至上章）」之前，附定位句（三合一）：「以下是上一章正文的结尾原文，本章第一段从这里直接接下去写；原文里已有的画面与信息不重述；衔接画面与章末落点摘要有出入时，以这段原文为准。」
  - `material_markdown`：【上章结尾（原文）】，插在【前情上下文】之后，带同款定位句。
- 定位句仲裁口径的由来：写手偏离落点是常态（真书 ch2 活例——落点写「局面未定」，正文写成了完全不同的画面），语义前情与原文尾段并存时模型必须有裁决规则；硬切豁免产出的自造钩子也只活在正文里，尾段是它流到下一章的唯一载体，仲裁句让它的衔接权重明确。摘要管事实，原文管衔接。
- 与「故事状态块注入」同手法（代码单源渲染＋两路同源＋空缺逐字一致），spec 已按此口径写。

### D2. 写作模板改动点（write_chapter.prompt，全在 system 恒定层）

- 输出契约新增一条「章首接点」（排在第 6 条结构强禁令之后为第 7 条，避免重排既有编号）：条件句措辞「素材含『上章结尾』时」触发——规则文本常驻、逐章字节一致，前缀缓存不破（spec 场景钉了逐字节一致）。
- 第 5 条「章末切点」**重排为分点结构**（停在哪→末句形状→一个示范→短禁令→豁免），既有禁令全部保留（总结/收束/感慨/反刍/末句搭台）但不得把新增内容继续堆进原 150+ 字复合长句——负禁令密度是遵循率的敌人，最重要的规则值得占版面；硬切正面锚示范内嵌其中（解决问题→转身要走→一声「哪里走！」→即止），并确认「示例人名与场景不得进入正文」免责句的作用域措辞覆盖输出契约（现文案挂在「写法要求」节尾，实现时把该句上移为模板级或在示范句内自带「例如」边界）。
- 章末钩子豁免写在第 5 条内单点表达（不在第 2 条开交叉引用）；豁免触发条件用可判定表述：「章末落点缺失或为局面陈述」；豁免句内同条保留悬念道具禁令（凭空新谜团/与本章前章无关的神秘登场/异象信物）；豁免含收束 carve-out——落点/章纲带收尾、结局语义（末章收束、完本）时停在落点本身不另起动向，与拆章侧末章例外对称，防卷末收束被硬加钩子。
- system 触发词统一用「上章结尾」（不带「（原文）」括注）——润色指引允许调整段标题措辞，而润色锚要求保留「上章结尾」，触发词取两者交集才对润色产物稳定生效。
- `WRITE_CLOSING_LINE`（chapter_writer.py:87-91，user 最末字节重申行）措辞同步：追加「末句落在动作、台词或声响上；落点是局面时以一句未展开的新动向硬切」。机制不动（不落库、不进预览）。
- 分层闸门（test_prompt_layering）不受影响：system 段首行身份句不动，changelog 注释行按惯例更新版本说明（v5）。

### D3. 拆章/自检模板（chapter-plan-ai 域）

- `chapter_split.prompt` 规则 4 全句重写：结尾停在「下一拍要砸下来的动向」（已在本章/前章登场的人物/势力或悬决之事砸出的新压力：来人、一句话、一条消息、一个决定），写成动作或台词瞬间；SHALL NOT 写成局面陈述；悬念道具禁令收窄（禁凭空新谜团/与本章前章无关的神秘登场/异象信物，已登场势力砸下一拍不算）。
- 同模板输出契约 `ending` 字段定义（:22「停在场面状态（剧情自然断点）——下一章才接得住」）同步改口径；`plot` 的「结果仍带局面」不动。
- **末章边界规则原样保留**（规则 9：末章收在卷纲第四问「预期结局」，收束口径）——新断章口径只管非末章；规则 9 一字不动，实现时 grep 复核别顺手改。
- `chapter_selfcheck.prompt` 拉力维问句改写：「结尾停没停在下一拍要爆发的一瞬——末句落在动作/台词/声响上，还是旁白总结或定格收束？」防硬造悬念口径同步收窄。四维闭集（反转/递增/推进/拉力）与 JSON 契约不动。
- `test_chapter_plan_ai_t3.py:733-764` 三处断言（"自然断点" in rule4 / "停在场面状态（剧情自然断点）" in src / 拉力问句）改钉新口径。
- 进场派生兼容性（已实证，ai_plan.py:68-99 `resolve_prev_chapter_ending`）：进场是服务端**派生字段**而非模型输出——上一章有正文→取正文末段（标「取自正文结尾（写到那里之后，这里以实际为准）」），无正文→落点拟定；拆章提示词硬规则 1「所有方向接同一条进场」吃的就是这个派生值。**提示词层无进场口径可改，本 change 不动拆章进场措辞**；该分流（正文优先＋以实际为准标注）与 D1 素材注入同源同哲学（原文为准），两端天然对齐。
- **顺手收口的同款病**：进场取文 `paras[-1][:200]` 硬截无句边界回退——长段会被切成残句开头，拆章模型的剧情第一拍据此规划就会接歪。修法：从 D1 的裁剪逻辑抽 `_clip_to_sentence_boundary(text, max_chars)` 小函数单源，进场取段改走句边界回退；spec 已在「拆章卡面」delta 钉住（进场 SHALL NOT 以残句开头）。这是拆章侧唯一的代码改动。
- 拆章素材双源说明（不动）：素材①进场（正文结尾优先，带来源标注）与素材⑧上一章一行剧情（章纲级摘要）在写手偏离落点时会不一致——①自带「以实际为准」定位，模型有明确优先级信号，与写作端仲裁句同构；重拆低频，不再加码。

### D4. 润色通道同步（prompt-crafting 域）

- `prompt_crafting.prompt`：要素清单第 3 条（前情上下文）扩尾「素材包含【上章结尾（原文）】时原文原样透传，不得摘要化」；锚词行（:27）追加条件锚「上章结尾（仅当素材包含对应块时）」。
- `validate_polished_prompt`（chapter_writer.py:314）：`ctx.previous_tail` 非空时产物须含「上章结尾」段标题锚，与「前情」条件锚同手法。
- 存量兼容：条件锚只在素材含块时生效；真书存量 `chapter_prompts` 均为粗组直写稿（无旧润色产物挡路），素材侧改动对新章生成即时生效。

## Risks / Trade-offs

- **素材膨胀**：每章直写/润色多 ≤800 字（~500-600 token）。对照真书 ch2 素材 2862 字，增幅 ~28%，可接受；system 恒定层零变化。
- **回退场景双文本风险已消除且口径更优**：回退块化后同一段正文只出现一处；旧书（章纲全空）从「无接点铁律」升级为「有块＋有章首接点」。
- **ghost 章选取不一致（存量，登记不扩 scope）**：写作端 `_prev_chapter_ref` 未过滤 ghost 章，拆章进场 `resolve_prev_chapter_ending` 有过滤——支线副本在场时两路「上一章」可能不同。存量行为、非本 change 引入；真机若复现再立项。
- **硬切豁免被滥用**（模型借豁免加戏）：豁免句限定「一句、未展开、已登场势力」，且悬念道具禁令同条保留；真机抽检若发现滥用，收窄为「仅当落点为局面陈述时」。
- **拆章模型适应期**：ending 从「局面」改「动作瞬间」，出卡质量可能有波动（字数预算 ≤80 不变）；既有降级阶梯与重试机制兜底，无服务端新断言（本 change 全部为提示词层约束，不动机判）。
- **改 prompt 必 grep e2e 桩短语**（既有纪律）：当前 grep「自然断点/局面未定/章末切点」在 e2e 无命中；实现时改模板前后各 grep 一次全量确认。
