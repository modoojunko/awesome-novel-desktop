# c-kb-summarize · 实例素材与知识总结管线——图谱由总结生成

## Why

数据模型口径（boss 拍板 2026-11-06）：**实例是事实层，知识是总结层，图谱是总结的产物**。现状偏离：手录一句话直接建知识（同句既当指令又当示范段槽位）、拆书收录直接建知识（收录卡原文当知识行）、AI 整理只产关系不产知识、知识定义「待补」靠作家手写——「知识」没有提炼层，图谱的上游是未经总结的原始卡。本 change 把录入两链路改产**实例素材**，新增大模型总结管线（素材聚类 → 提炼知识点 → 作家确认 → 建知识＋挂实例），让知识图谱真正由总结生成。

## What Changes

- **实例素材态（模型归位）**：`kb_entries.origin` 枚举新增 `material`——手录与拆书收录落库为素材行（语义＝一条待总结的实例素材），消费端（知识列表默认视图、星图、选择器、写法块、书级副本）一律排除素材行；素材行带「素材」标在列表可见、可查看原文、可删除
- **总结管线（新增）**：按题材×概念聚类素材行 → LLM 提炼候选知识（知识名＋知识定义＋素材归组）→ 作家确认制采纳 → 采纳后建知识行（`origin='summary'`）＋素材行转挂为该知识的实例（kb_knowledge_instances）＋素材行归档；运行记录独立落表，同 genre 单飞
- **触发**：手动（知识整理面板「总结知识点」）＋自动（某题材素材积压 ≥5 条时启动期触发一次）；提示词仓新增 `kb_summarize` 模板（缺失 fail-soft 同既有整理口径）
- **存量豁免**：已建知识行（origin=manual/deconstruct 等）原样保留，总结管线不回扫；管线的对象只有素材行与增量
- **知识树与图谱**：知识间新增**上下层关系**（`kb_entries.parent_id`，概念为根、知识分层成枝干、叶子知识挂实例群）——总结管线提炼候选时带层级归属（挂概念根或挂某知识下）；星图从「题材→概念」两层升级为**树形图谱**：概念根星 → 知识枝干分层展开（层级边），六类关联关系横向连线（关联边），实例不进图（点叶子知识开卡看实例群）——形成「一棵树，叶子知识挂很多实例」的图谱形态
- **不改动**：AI 关系整理链路（关系仍由整理产）、编辑器对真知识行的补写路径、选择器与写法块的消费逻辑（只新增素材过滤）

## Capabilities

### New Capabilities

（无——全部落在既有 knowledge-base 能力）

### Modified Capabilities

- `knowledge-base`:
  - **ADDED**「实例素材与知识总结」：素材态语义、消费端排除、总结管线（触发/聚类/提炼/确认制/采纳转化）、运行记录、存量豁免、提示词缺失 fail-soft
  - **MODIFIED**「知识条目数据模型」：origin 枚举新增 `material`（素材态）；「一条手法知识入库」scenario 改写——拆书收录落素材行（不再直接建知识行）
  - **MODIFIED**「知识编辑器与种子」：手录落素材行（一句话＝素材，不再直接建知识）；编辑器只对真知识行（含 summary）开放
  - **MODIFIED**「知识库浏览界面」：素材行在列表带「素材」标可查看可删除，SHALL NOT 进星图/选择器/写法块；知识整理面板新增「总结知识点」入口与候选确认清单
  - **MODIFIED**「知识星图视图」：图谱升级为知识树——概念根星 → 知识分层枝干（层级边）＋六类关联横向边；叶子知识开卡见实例群；WebGL 降级与题材筛选口径不变

## Design Impact

- **受影响端**：C端 only（S端不动）
- **受影响的屏/弹层**：知识库列表（素材行标）、知识整理面板（总结入口＋候选确认清单＋采纳交互）、知识视图抽屉（素材行的只读态）、手录表单（提交后文案＝素材已收录）
- **对象状态**：素材行 `origin='material'`＋active/archived 复用；候选 `pending/adopted/dismissed`；知识行新增 `origin='summary'`——不新增全局状态词
- **是否触碰两端共享段**：不触碰 base.css 与 design-system 共享段；素材标复用 pill-tag 既有形态
- **是否需要原型先行**：**否**——整理面板已有候选清单先例（KbOrganizePanel 待确认清单），素材行复用列表行版式＋标签
- **设计工件产出**：实现侧自查（文案 §13：按钮动词、无内部术语；「素材」「总结」面向作家措辞待 §13 复核）
