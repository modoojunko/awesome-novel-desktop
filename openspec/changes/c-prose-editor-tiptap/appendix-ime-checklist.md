# 附录：IME / 编辑器内核迁移手测清单（c-prose-editor-tiptap）

自动化覆盖不了的输入法组合期行为，合并前/后按此清单在**桌面端真机**过一遍（约 10 分钟）。
每项的预期都对应 spec「正文编辑器核心契约」。

## A. 拼音组词（核心）

1. 进入正文编辑态，用拼音输入一个长句（如「今天下午我要去图书馆还书」），组词中途**停顿 3 秒**再上屏 → 候选窗不消失、不丢字母、上屏内容完整落在所在段落。
2. 组词中途**连续敲键不选词**（让候选窗翻页）→ 无文字被吞、无重复。
3. 组词中途**切出窗口再切回**（Cmd+Tab）→ 组合不残留半截字母，已上屏内容完好。
4. **英文混打**：打完 English 紧接着切中文打「中文」→ 无输入法状态错乱。

## B. 撤销/重做

5. 手打两段 → Ctrl/Cmd+Z 逐次撤销，一次一步；Cmd+Shift+Z 重做。
6. AI 生成正文完成 → **一次撤销回到生成前**；重做恢复生成结果（spec 场景）。
7. AI 生成中途点「停止」→ 撤销回到生成前，已落盘的部分随收尾保留（与现口径一致）。

## C. 粘贴

8. 从网页复制一段**带加粗/标题/图片**的内容粘贴 → 只留纯文本与段落，图片不进。
9. 从 Word 复制多段粘贴 → 段落结构保留（不挤成一段）。
10. 粘贴后自动保存落库，后端直查 `prose` 无 HTML 标签残留。

## D. 回归抽查

11. 「编辑正文」两态、归档/排队/旧稿三种只读横幅照旧（c-prose-edit-gate 口径）。
12. 段首缩进/字号行距偏好/680 版心呈现不变；空章占位提示可见。
13. 字号统计（编辑器底栏与头部 e-meta）与实际字数一致（NBSP/空段不虚增）。
