# Tasks: c-prompt-pack-hardening

> 前置：无跨仓依赖（S端 / CDN / 发布链零改动）。本 change 纯 C端 单侧，可独立验收。
> 落地顺序＝先形态与密钥（1）→ 读路径（2）→ 迁移（3）→ 原生化（4）→ 卫生与回归（5/6）。
> 每组的实现都不得出现「明文可用态」——任何失败路径只能走「未装包/沿用现态」。

## 1. 落盘形态与本地密钥

- [x] 1.1 新增本地密钥模块（生成/解封/封装 LWK）：Windows 走 DPAPI 用户作用域、macOS 走 Keychain、其余回落机器指纹派生并在状态里标注弱保护档；单测覆盖「封装→解封往返」「密钥文件损坏→按未装处理」。
- [x] 1.2 定义容器格式（`pack.bin`＝nonce||AES-GCM 密文，明文负载 `{schema,templates}`，AAD 绑版本）＋读写工具；单测覆盖「换密钥不可解」「换版本目录不可解（AAD 生效）」「同密钥往返一致」。
- [x] 1.3 `sync.py::_install()` 落盘改为写容器（不再写 `{name}.prompt`），receipt 的 `templates` 哈希语义保持对**模板文本**；单测断言安装后包目录内**零**可直读模板文本（含对目录做全文扫描的负面断言）。
- [x] 1.4 安装失败矩阵与回滚位适配新格式（原来靠明文目录回滚，现在回滚位也是容器）；单测覆盖「安装中途失败→沿用上一版容器」。

## 2. loader 读路径（内存解密、零中间文件）

- [x] 2.1 `prompts/__init__.py` 读路径改为「读容器→内存解密→按 receipt 哈希校验→返回」，解析序（已装版本目录→开发/测试态包内目录→`PromptPackMissing`）与 `min_client_version` 拒载语义不变；单测：读前后包目录内容零变化（负面断言无新增文件）。
- [x] 2.2 开发/测试态（`PROMPT_PACK_MODE` 未开）直读包内目录的行为逐字节不变；跑存量 `test_prompt_pack*.py` 与相关 loader 测试全绿。
- [x] 2.3 `prompt_pack/__init__.py` 的 `verify_file` / 目录解析适配容器；单测覆盖「容器被改→读时校验失败→按缺失回落」。

## 3. 存量迁移（明文包 → 容器）

- [x] 3.1 启动补偿钩子检测「版本目录内存在 `.prompt` 明文」→ 就地读入并写容器 → 原子替换 → 删除明文；单测覆盖成功路径与「转换中途失败→按未装包处理（不得退回明文可用）」。
- [x] 3.2 迁移后离线可用性验证：模拟断网（monkeypatch 出站）跑迁移 → 模板可读、AI 不触发新网络请求；测试记入 `test_prompt_pack_sync.py`。
- [x] 3.3 迁移的日志卫生：过程日志只含版本号与枚举 reason，单测断言日志文本不含任何模板片段。

## 4. 关键路径原生化（达到成本线的必要条件）

- [ ] 4.1 选型落地（Cython 编译单模块或等效方案），把「解封 LWK＋容器解密」移入原生模块；Python 侧只接收解密后文本。验证：`python -c "import <native>"` 可用且单测向量通过。
- [ ] 4.2 Python 字节码里不再含有密钥材料与解密参数：静态扫描断言（在打包产物 `_internal` 的 pyc/源码里 grep 关键常量与算法参数应为零命中）。
- [ ] 4.3 构建链接入两端：`build.spec`/CI（client-package.yml）与 `build_release.ps1` 各加编译步骤＋冒烟断言「原生模块存在且自解密自检向量通过」；构建失败即红（不得静默降级）。
- [ ] 4.4 反证用例（探针式）：临时把解密路径改回纯 Python，断言静态扫描用例变红——确保这条门禁不是摆设。

## 5. 卫生与失败矩阵

- [x] 5.1 全链排查并切断模板文本外泄面：日志/异常/状态接口/诊断页；单测或静态断言覆盖（含 `%TEMP%` 零中间件）。
- [x] 5.2 密钥不可用（换机/换用户/系统重装）时：按未装包处理 → 联网重下；离线时呈现既有「写作能力未就绪」，不弹新错、不新增提示面；单测覆盖两条分支。
- [x] 5.3 回归一轮全量：`client/backend` pytest 全绿；前端 vitest 全绿；确认无新增状态/文案（无 UI 改动）。

## 6. 验收与发布

- [ ] 6.1 手工验收脚本（Windows 真机）：装包 → 检查包目录无明文（含 grep）→ 断网用 AI → 拷整个 `prompt-pack` 目录到另一台机器/另一用户 → 显示「写作能力未就绪」且不回落明文。
- [x] 6.2 性能基准：容器单次解密耗时记录在案（实测 341KB 包 open 中位 **15.3ms**、p95 16.2ms；AI 调用时延以秒计，故不引入缓存——D3 的「默认关」成立）。
- [ ] 6.3 macOS 真机验证 Keychain 行为（首启授权形态、会话保持），结论回填 design 的 Open Questions。
- [ ] 6.4 release notes 补一句「换机/重装后首次使用 AI 需联网重下写作能力包」，避免用户误判缺陷。
